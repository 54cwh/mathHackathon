# 可视化（viz）

> **管辖范围**：本文件拥有——出图模块的**清单与映射**（`scripts/*.py` 薄壳 ↔ `viz/*.py` 模块）、各模块的**输入 / 输出 / 只读约束**、图 ↔ Excel 数据表的导出契约（`figdata.py`）。不拥有——指标定义与统计口径（`experiment/实验与评价体系.md` §2）、图的编号与内容权威出处（`paper/图表-数据对照表.md` §2、`core/核心机制与数据流.md` §2）、被消费数据对象的字段定义（各 producer 模块）。（层级与归属见 `AGENTS.md`「文档层级与优先级」。）
> 状态：**v1.0（2026-09-26 可视化代码自 `scripts/` 迁入 `viz/`）**。

## 1. 定位

`viz/` 负责出图，**只读** `results/`（run 目录 / 汇总表 / 落盘产物），不重算口径、不重新发育。图上的每个尺寸数字都取自被消费的落盘产物或 `pipeline` 的产出，改样式不改数据。

`scripts/make_fig_*.py` / `scripts/make_figs.py` / `scripts/make_env_compare.py` 是**薄 CLI 壳**：只调用 `evogenesis.viz.*::main`，命令路径与参数不变（`AGENTS.md`：`scripts/` 只做参数解析与调用）。argparse 在模块内。

路径基准：`viz/paths.py::REPO_ROOT`（包内向上三级定位仓库根；`scripts/` 里 `Path(__file__).parents[1]` 的写法在包内会算错，故统一收口）。

## 2. 脚本 ↔ 模块映射

| CLI（薄壳，路径不变） | 模块（业务逻辑 owner） | 输入（只读） | 输出 |
|---|---|---|---|
| `scripts/make_figs.py` | `viz/figs.py` | `results/runs/<id>-s*/{metrics.csv,population.jsonl,episodes.jsonl}`、`results/tables/<id>_summary.json` | `results/runs/<id>-s*/plots/`、`results/figs/<id>/`（+ 同名 `.xlsx`） |
| `scripts/make_fig_connectome.py` | `viz/fig_connectome.py` | `results/tables/connectome_matrix.json`（由 `scripts/dump_connectome_matrix.py` 落盘） | `results/figs/connectome/`（+ `data/*.xlsx`） |
| `scripts/make_fig_pipeline.py` | `viz/fig_pipeline.py` | `core §2`（脚本内节点/边表，逐条标出处） | `results/figs/pipeline/`（+ `data/*.xlsx`） |
| `scripts/make_fig_viability.py` | `viz/fig_viability.py` | 固定 master seed 现场发育（`development` / `genome`），非 `results/` | `results/figs/dev_viability/`（+ `data/*.xlsx`） |
| `scripts/make_env_compare.py` | `viz/env_compare.py` | `results/tables/exp_env_*_summary.json`、`results/runs/exp_env_*` | `results/figs/env_compare/`（+ `data/*.xlsx`） |

**数据落盘不属 viz**：`scripts/dump_connectome_matrix.py`（F7 数据层）与 `scripts/probe_architecture.py` 产出可追溯 JSON/CSV，供 `viz` 消费；它们不画图，留在 `scripts/`。

## 3. 图 ↔ 数据表契约（`viz/figdata.py`）

长期要求（用户 2026-09-26）：**一图一 `.xlsx`**。

- 命名对应：`figs/<exp>/fig_x.png` ↔ `figs/<exp>/data/fig_x.xlsx`（同名不同后缀）。
- 首 sheet 固定 `_manifest`：逐 sheet 写明 caption / 形状 / 来源，不看代码可知含义。
- 其余 sheet 为**原始数据**（未经美化），供改样式不改数据。
- 守护测试：`tests/test_figdata.py`；各图另有 `tests/test_fig_*.py`。

## 4. 与代码的映射

- `viz/paths.py`：`REPO_ROOT`。
- `viz/figdata.py`：`export_workbook` / `workbook_path` / `data_dir` / `MANIFEST_SHEET`。
- `viz/figs.py`、`viz/fig_connectome.py`、`viz/fig_pipeline.py`、`viz/fig_viability.py`、`viz/env_compare.py`：各含 `main(argv=None) -> int`。

引用/展示口径以 `paper/图表-数据对照表.md` 为准（本文件不定义图的编号与论证内容）。
