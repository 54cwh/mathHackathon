# 问题定义与研究假设

## 1. 数学定义
给定人工二倍体基因组：

\[
G=(H^{(1)}_1,H^{(2)}_1,H^{(1)}_2,H^{(2)}_2)
\]

每个 \(H\) 为长度 128 的 A/C/G/T 序列。

定义：

\[
D_\Theta:G \mapsto (A,Z,\tau,W^{(0)},M)
\]

其中 \(A\) 为连接矩阵，\(Z\) 为 cell identity，\(\tau\) 为时间常数，\(W^{(0)}\) 为发育得到的初始连接强度，\(M\) 为 active neuron mask（存活/成神经元标记，用于 padding 与 masking）。

依据：genome→connectome 映射与"遗传信息先于网络结构"的立论来自 genomic bottleneck / developmental encoding `[bib#1][bib#2][bib#3]`；由发育规则（cell type / distance / pruning）生成 connectome 的形式见 `[bib#4]`。文献编号见 `research/notes/bibliography.md`，依据分级见 `docs/设计依据审计.md`。

生命周期学习：

\[
W^{*}=L(W^{(0)},A,Z,\tau,\mathcal D,K)
\]

其中 \(Z,\tau\) 为固定条件（决定 DanioNet 前向动力学），\(L\) 只更新连接权重。

环境交互：

\[
\mathcal T = \Pi(A,Z,\tau,W^{*};E)
\]

fitness：

\[
F=\mathcal F(\mathcal T,E)
\]

代际更新：

\[
\mathcal P_{t+1}=\mathcal R(\mathcal P_t,F,\mu,r)
\]

## 2. 研究问题
- RQ1：紧凑 genome 是否能通过 RGCD 生成多样且可运行的 DanioNet？
- RQ2：单碱基变化能否经 motif → GRN → connectome 产生连续或突变式结构变化？
- RQ3：异质 \(\tau_i\) 与发育生成稀疏拓扑是否改变性能、效率或鲁棒性？
- RQ4：不同环境是否改变 genotype、network phenotype 与 behavior 的选择结果？
- RQ5：Mendelian segregation 能否映射成 architectural segregation 和 behavioral segregation？

## 3. 假设
H1：不同 genome 在相同 seed 控制下产生系统性 connectome 差异。

H2：connectome 与 neuronal dynamics 差异导致行为差异。

H3：异质 \(\tau_i\) 在历史依赖任务中形成与 homogeneous-\(\tau\) 不同的性能—效率权衡。

H4：spatial wiring cost 改变网络局部性、稀疏性与 active-edge efficiency。

H5：fitness 依赖环境：

\[
F=F(G,E)
\]

不存在对所有环境都必然占优的 genotype。

## 4. 建模假设
1. 人工 genome 不等于真实斑马鱼 genome。
2. motif、GRN 节点及权重为人工调控系统。
3. developmental coordinate 是二维抽象发育空间。
4. 六类 neural fate 是功能抽象。
5. structured sensory vector 代替 raw pixels。
6. generation 是计算实验时间尺度。
7. growth 是生态游戏化抽象。
8. fitness 是任务定义量。
9. predator/prey 用透明规则控制器。
10. 后天权重不遗传。
11. 有限种群随机繁殖自然产生 drift。
12. environment 在单 episode 内固定，代际之间可切换。
