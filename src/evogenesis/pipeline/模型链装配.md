# 模型链装配（pipeline/）

> **管辖范围**：把已冻结的模块**串成一条可执行链路**的编排（`config → motif 目录 → 初始种群 → q(G) → 发育 → DanioNet → (ω,v)`）。**不拥有**任何算法、数值或契约：参数取值归 `configs/*.yaml`，字段名/类型归 `schemas/` 与各模块文档，机制归 `core`。（层级与归属见 `AGENTS.md`「文档层级与优先级」。）
> 状态：**v1.0 已定稿（冻结 2026-09-26）**。

## 1. 链路

```text
configs/default_model.yaml
  ├─ genome 节      → GenomeLayout        （genome §2）
  ├─ grn/development/connectome 节 → RGCDConfig（RGCD §13）
  └─ network 节     → NetworkReadoutConfig（DanioNet §）

master_seed ─┬─ motif_catalog 命名空间   → motif 目录（genome §6）
             ├─ initial_population 命名空间 → 初始种群基因组（genome §2）
             └─ development 命名空间       → 单个体的 (A,Z,τ,W⁰,M)（RGCD §1–§11）

genome ──q(G)=genome_affinity──► develop ──ConnectomePhenotype──► DanioNet.step(obs) ──► (ω, v)
```

## 2. 入口（`pipeline/model_chain.py`）

| 函数 | 作用 |
|---|---|
| `load_model_chain_config(path=None) → ModelChainConfig` | 读 `default_model.yaml`，分别经 `load_genome_config` / `load_development_config` / `load_network_config` 得三段配置 |
| `initial_population(*, master_seed, experiment_id, n, layout) → tuple[ChainIndividual, ...]` | generation 0 种群：`random_genome` 均匀 i.i.d.（`genome §2`） |
| `motif_catalog(master_seed, layout) → tuple[str, ...]` | 实验级固定 motif 目录（`motif_catalog_for`） |
| `phenotype_of(genome, motifs, *, master_seed, index, config, device) → ConnectomePhenotype` | `q(G) → develop` |
| `phenotypes_of(individuals, motifs, *, master_seed, config, device) → list[...]` | 批量发育，`index` 取个体在种群中的稳定序号 |
| `danionet_of(phenotypes, *, master_seed, config, device) → DanioNet` | 由发育产物构造网络（batch = 个体数） |
| `viable_pairs(individuals, motifs, *, master_seed, config, device)` | 发育并保留 `viable` 个体（`RGCD §7`） |
| `run_arena_episode(individuals, *, master_seed, chain, arena_config, steps, generation) → ArenaEpisodeResult` | 用 DanioNet 驱动 Arena 跑一局 |
| `arena_seeds_for(master_seed, index=0) → (int, int)` | Arena 两个整数子种子：`(arena_spawn, arena_dynamics)`（`core §3`） |

## 3. 种子与 ID（唯一来源）

- 随机源一律经 `core/seed.py` 的 `SeedManager`：`motif_catalog=4`、`initial_population=7`、`development=2`、`network_init=5`（`core §3`）；**Arena 的两个整数子种子**由 `arena_seeds_for(master_seed) → (SeedManager.seed("arena_spawn", 0), SeedManager.seed("arena_dynamics", 0))`（id=3 / id=9）派生后传入 `DanioArena(spawn_seed=..., dynamics_seed=...)`（`core §3` 整数种子例外条款），**不把根部 `master_seed` 直接交给 Arena**。
- `genome_id` 由 `core/ids.py::mint_id(experiment_id, "genome", 0, index)` 铸造（`core §3.1`）；`index` 为个体在种群中的稳定序号，**不使用调用顺序**。
- 数值不在此层：本模块不出现常量参数，全部由传入的 `GenomeLayout` / `RGCDConfig` / `NetworkReadoutConfig` 提供。
- `ChainIndividual`（本模块值对象：`genome_id` / `fish_id` / `genome`）与 `evolution §5.1 Individual`（含 `fitness` / `viable` / `failure_reason`）**不同物**，故用独立名避免同名混淆；二者共享 `core §3.1` 稳定 ID。

## 4. 已接 / 未接

**已接**：`config → motif → 初始种群 → q(G) → 发育 → DanioNet → (ω,v)`，以及 **Arena 单 episode 驱动**（`run_arena_episode`：只跑 `viable` 个体、`population.n_fish` 按实际数覆盖、死鱼观测置零且不产动作、全 batch 前向）。**生产入口 = `scripts/run_chain.py`**（薄 CLI：读 `default_model.yaml` + `default_arena.yaml`，跑一代 DanioNet 评估，落 `metrics.csv`/`events.jsonl`/`seed_summary.json`）。`tests/test_pipeline.py` 与 `tests/test_chain_cli.py` 守护（含同 seed 确定性）。

**未接（各自 owner / 待定）**：
- **`fish_id ↔ Arena 身份`**：已定——`ChainIndividual.fish_id`（`core §3.1`）直接作为 Arena 实体 id（`DanioArena(fish_ids=...)`），`per_fish_log` 以稳定 `fish_id` 为键；并把 `ChainIndividual.genome_id` 经 `genome_ids` 写入 `Fish.genome_id`（轨迹 `genome_id` 字段，P0-9 闭合），`run_arena_episode(..., generation=)` 透传本代代数。Arena 不传时保留旧默认（`fish_XX` / `"unknown"`，向后兼容）。
- **A14（arena 随机源）——已闭合（2026-09-26）**：`arena_spawn=3` / `arena_dynamics=9` 两条流已拆分；`DanioArena(spawn_seed=..., dynamics_seed=...)`，编排层经 `arena_seeds_for` 派生。
- **逐代演化**：`evolution/population.py::advance_generation` 已就绪，缺"评估回填 fitness → 下一代"循环（`run_chain.py` 目前只跑**一代**）。
- **BC 学习**（`learning`）未在本链路内接（其数据由 `experiment/collect.py` 独立采集）。

## 5. 代码映射

- `src/evogenesis/pipeline/model_chain.py`：§2 的入口。
- 依赖：`evogenesis.{genome,development,connectome,arena,core}`；不反向依赖 `evolution` / `experiment` / `learning`。
- `src/evogenesis/pipeline/arena_episode.py`：§4 的 Arena 驱动（`viable_pairs` / `run_arena_episode` / `ArenaEpisodeResult`）。
