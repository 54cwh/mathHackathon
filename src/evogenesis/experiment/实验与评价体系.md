# 实验设计与评价体系

> **管辖范围**：实验协议、指标定义、`results/runs` 目录布局与正式结果原则；环境对照三组取值。（层级与归属见 `AGENTS.md`「文档层级与优先级」。）

## 1. Reproducibility
Demo seed 与 research seeds 分离。

正式结果至少：

\[
n=3
\]

random seeds，报告 mean ± std。

## 2. Experiment A — Genome → Architecture
采样 genomes，记录：
- motif affinity
- GRN final states
- neuron count
- cell-type distribution
- edge density
- tau distribution

## 3. Experiment B — Single-base Mutation
对代表性 haplotype 的 256 positions 逐位做 deterministic alternative-base mutation。

计算：

\[
\Delta Expression,\quad d_{edge},\quad d_\tau,\quad \Delta Behavior
\]

生成 Genome Sensitivity Map。

## 4. Experiment C — Baseline
- MLP
- GRU
- Fixed Sparse RNN
- DanioNet

控制：
- 相同数据
- 相同训练预算
- 参数量同一数量级
- 相同 evaluation episodes

指标：
- survival
- prey capture
- escape success
- energy efficiency
- inference latency
- parameter count
- active edges

指标定义（供 §9 与 fitness 复用；出处 `research/reference/design-basis-metrics.md`）：
- survival = `survival_steps / episode_steps`
- prey capture = `captures / max(capture_attempts, 1)`
- escape success = `escape_successes / max(predator_encounters, 1)`
- energy efficiency = 净能量积累率简化式 \(r_i=(E_i(T_i)-E_{max})/T_i\)（MVP；口径见 `core/核心机制与数据流.md` §10 #12）
- inference latency = 单步前向延迟 p50/p95（warmup 后测得）

> H2 需专门分析：connectome 与行为矩阵的 **Mantel 检验**（本表未单列，见 `问题定义与研究假设.md` §2 映射表）`[bib#21]`。

## 5. Experiment D — Ablation
- Full DanioNet
- w/o GRN
- homogeneous tau
- w/o spatial wiring cost
- BC 有 / 无 Dale 符号约束 `[bib#30][bib#31]`
- P1：w/o epistasis

## 6. Experiment E — Robustness
随机删除 active edges：
- 5%
- 10%
- 20%

比较 behavior / fitness degradation。

## 7. Experiment F — Environmental Selection
相同 initial population 分别进入：
- Food Rich
- Predator Rich
- Resource Scarce

运行 10–20 generations，记录：
- allele frequency
- phenotype frequency
- viability
- fitness
- neuron count
- edge count
- tau statistics

## 8. Mendelian validation
大量 offspring 验证 AaBb × AaBb。显示 empirical ratio，并计算：

\[
\chi^2=\sum_i\frac{(O_i-E_i)^2}{E_i}
\]

统计波动属于模型正常结果。

## 9. Active-edge efficiency
\[
\text{active-edge efficiency}=
\frac{TaskPerformance}
{ActiveConnections\times Timesteps}
\]
（命名与图论 efficiency 区分 `[bib#22]`；旧称 `Efficiency` 易混淆。）

同时单独报告：
- parameter count
- active edges
- latency
- peak memory（可测时）

## 10. 正式结果原则
- 不人工挑选最好一次作为结论。
- Demo 可使用稳定 seed。
- 正式结果必须来自固定 protocol。
- 所有图可回溯到 run directory。
