## 1. 目的与职责
在不改变遗传通路的前提下，让**当代个体**通过模仿专家行为获得运动能力。**训练粒度（定稿）**：**每个当代个体各自训练自己的 `DanioNet`**（同一份专家数据、各自的 `Θ`），因为 DNA 不同 ⇒ 网络不同，`ΔW` 是当代个体专属；**BC 只训练 `Θ`**，`ΔW = W − W⁰` 为导出量（契约见 `connectome/DanioNet设计规范.md` §3）。测量的是"同一 DNA 经学习能得到多好的行为"，而不是把学习结果遗传下去。

## 2. 数据来源与规模（Stage 1 专家轨迹）
- 教师：透明规则控制器 `ExpertPolicy`（视野内追踪最近猎物、按威胁与障碍转向），可解释、可写进论文。
- 采集：`ExpertPolicy` 在 Arena 标准 episode（30 s / 600 steps）中驱动鱼，逐 step 记录 `(observation, expert_action)` 样本。
- **规模**：标准预算 `bc_trajectories = 200` 条 episode（每条 600 步，合计 ≈ 1.2×10⁵ step 样本）；最小验证可先取 10–50 条。数据量消融取 10 / 50 / 200 三档。依据：robomimic 每任务 200 条演示 `[bib#34]`。
- 字段与维度见 `core/核心机制与数据流.md` §4.2：`observation` 为 **12 维**感知向量（顺序冻结），`expert_action` 为 **2 维** `(ω*, v*)`。
- **采集粒度（定稿）**：每条 episode **只记录 1 条受控鱼**的 `(observation, expert_action)`；环境中其余个体照常存在（提供真实的感知上下文），但**不入轨迹**。故样本数 = `bc_trajectories × 600`，与上文 ≈1.2×10⁵ 一致。
- **其余个体（定稿）**：环境内其余个体同样由 `ExpertPolicy` 驱动（保持环境行为一致），但**不入轨迹**；受控鱼固定为 index 0，其稳定 `fish_id`/`genome_id` 经 `core/ids.py::mint_id(experiment_id, role, generation, index)` 铸造，并经 `fish_ids`/`genome_ids` 注入 Arena（轨迹身份与 Arena 实体一致）。轨迹**记录满 `episode_steps`**（Arena 跑满，`arena §15` A9）；schema 的选填字段（`reward` / `is_first` / `is_last` / `environment_config`）**不落盘**。
- **训练/验证划分（定稿）**：`bc_trajectories` 条**全部作训练集**——§3 的 σ 与 λ 均在其上计算；本版**不设 held-out**（`K×batch=1280` 对 ≈1.2×10⁵ 样本属极度欠拟合，验证集不改变结论）。如需泛化报告，另按 episode 序号固定切分并单独登记。
- **动作口径**：`ω*` 为 Arena 归一化转向、`v*` 为推进，均落在 `DanioNet §4` 的输出空间（`ω∈[-1,1]`、`v∈[0,1]`）。Arena 转向量纲（认领表 A10）若变更，§3 的逐维方差归一化会吸收尺度差异，故不阻塞本契约。

## 3. 训练契约（Stage 2）
- **前向与回传范围（定稿）**：`DanioNet` 为循环网络，且 `h⁰=0` 时 `W·h⁰=0` ⇒ 单步 `∂L/∂Θ ≡ 0`。故 BC **按 episode 顺序展开整段 BPTT**：每次更新抽 **64 条 episode**（有放回）为一 batch，每条自 `h⁰=0` 起前向满 `episode_steps`（现 600）步；损失先对该 episode 的逐步损失取**均值**，再对 batch 取均值后整段回传。
- **σ 口径（定稿）**：§3 的 `σ_i` 取训练集动作的**总体标准差（`ddof=0`）**；`R_ω=2`、`R_v=1` 为两维取值跨度。
- 预算：`bc_updates = 20` 次更新（`K = 20`）；`bc_batch_size = 64` **条 episode**。采样为**均匀随机有放回** episode mini-batch（配合整段 BPTT，采样单位是 episode 而非 step）。**覆盖率口径（定稿）**：以 episode 级报告 `K×batch / 总 episode 数`（=1280/200 = **6.4 个 epoch**），并同时给出 step 级可见样本 `K×batch×episode_steps`（=768,000）与其对 `bc_trajectories×episode_steps` 的倍数。
- 优化器：Adam，`bc_lr = 1e-3`。依据：主流 BC 实现默认 Adam `[bib#34][bib#210]`；`K=20` 短程 regime 的 lr 无直接文献，属设计选择。
- **损失与权重（定稿）**：按**目标尺度归一化**取权重，再求加权 MSE

\[
\lambda_i=\frac{1}{\max(\sigma_i,\ 0.05R_i)^2},\qquad i\in\{\omega,v\},
\]

\[
\mathcal L=\lambda_\omega \, MSE(\hat\omega,\omega^*)+\lambda_v \, MSE(\hat v,v^*),
\]

其中 \(\sigma_i\) 为 Stage-1 专家轨迹**训练集**上第 \(i\) 维动作标准差，\(R_\omega=2,\ R_v=1\) 为两维取值跨度（下限取 \(0.05R_i\) 防除零）；再整体缩放使 \(\lambda_\omega+\lambda_v=2\)。权重**计算一次后全实验冻结**。规则与其下限由 config 承载：`learning.loss_weight_normalization = per_dim_variance`（启用上式）、`learning.loss_variance_floor_ratio = 0.05`（即 \(0.05R_i\) 的比例）；未取到训练统计量时用**预注册回退值** `learning.loss_weight_fallback_omega = 0.4`、`learning.loss_weight_fallback_v = 1.6`——该回退值即下限比例 \(0.05\) 下按 \(R_i\) 的推导结果（\(\lambda_\omega:\lambda_v = 1/R_\omega^2:1/R_v^2 = 1:4\)，缩放至和为 2 得 \(0.4/1.6\)），非独立选定。该口径等价于对各维目标 z-score 后等权，\(\lambda\) 无量纲、非自由超参；归一化只改损失尺度、不改网络输出，`DanioNet §4` 的 \(\hat\omega=\tanh(y_\omega)\)、\(\hat v=\sigma(y_v)\) 有界映射保持不变。
- **实现边界（定稿）**：`σ` 需在**非空**训练集上算；训练集为空时 `train_bc` 报 `ValueError`，权重计算退回预注册回退值。`learning.loss_weight_normalization` 仅支持 `per_dim_variance`，其他取值抛 `NotImplementedError`。BC 采样的实体序号 `t`（`core §3`）由**调用方**按该个体 `genome_id` 给定（与配子级 `t` 同规则）。
- **禁用学习式权重**：极小预算（`K=20`）下不使用 Kendall 不确定性加权 / GradNorm `[bib#170][bib#171]`（需额外可学习参数与训练轮次），仅在讨论中列为扩展。
- baseline 与消融**共用同一组冻结权重**（连同数据、预算、标准化口径）。
- 公平性红线：基线 / 消融必须**相同数据、相同训练预算、相同标准化口径、参数量同一数量级、相同 evaluation episodes**（实验侧控制见 `experiment/实验与评价体系.md` §3.3）。**「相同 evaluation episodes」的精确含义（2026-09-26 定稿）**：评估局走 `core §4.2` 的独立命名空间 `arena_eval_spawn=15` / `arena_eval_dynamics=16`（`t` = 评估 episode 序号，全模型共享），**与采集侧 `arena_spawn`/`arena_dynamics` 解耦** —— 复用后者会使评估局与训练数据落在同一批环境实例上。
- 短程敏感性（`K=20` regime 无直接文献，须报告）：`bc_lr ∈ {1e-3, 3e-4}`、`bc_batch_size ∈ {32, 64, 128}`、`bc_trajectories ∈ {10, 50, 200}`。

## 4. 遗传边界（不可破坏）
训练产生的 \(\Delta W\) **不遗传**。后代只继承 DNA，从发育重新开始；BC 只影响当代表现型，绝不进入繁殖通路（见 `evolution/遗传繁殖与演化模型.md`）。

**报告口径（定稿）**：`flip_rate` 在**活跃支撑**（`A ∧ sign(W⁰)≠0`）上统计符号翻转占比；谱半径逐个体对 `effective_weights` 全矩阵取 `max|λ|`（padding/非活跃只贡献 0 特征值）。报告产物落盘位置 = `experiment/实验与评价体系.md` §5.1 的 `learning.jsonl` / `learning_summary.json`（编排 owner = 同文件 §3.8）。

**非遗传取证（定稿）**：以**可证伪**的判据承载「ΔW 不遗传」——训练后**重新发育同一 genome**，新网络的 `max|ΔW| < 1e-5`（float32 容差，非严格 0；约束路径 `softplus∘softplus⁻¹` 有舍入）且其 `W⁰` 与训练用网络**逐元素相同**。实现与产物见 `experiment §3.8`（`learning_summary.json::noninheritance`）。

**符号约束**：BC 只更新权重幅度，保持 \(sign(w_{ij})=sign(w^{(0)}_{ij})\)（参数化 \(w_{ij}=sign(w^{(0)}_{ij})\cdot softplus(\theta_{ij})\)）`[bib#29][bib#30][bib#31]`。须做"有约束 vs 无约束"消融（记录 BC 损失、任务指标、flip_rate、谱半径）。

## 5. 驱动归属（定稿）
同一条鱼在不同阶段由不同 driver 输出动作 `(ω,v)`：

| 阶段 | driver | 说明 |
|---|---|---|
| Stage 1 采集 | `ExpertPolicy` | 产生训练数据 |
| Stage 2 训练 | 不仿真 | 只更新 `ΔW` |
| 评估 / 演化 | **`DanioNet`** | 鱼由自己的网络驱动，动作经 `DanioNet §4` 的 \(\tanh/\sigma\) 合成；`ΔW` 参与**当代表型**、不遗传 |
| Live Demo | `ExpertPolicy` | 演示教师行为 |

若评估阶段仍由 `ExpertPolicy` 驱动，则 DNA 与学习都不影响行为、适应度失去意义，故评估**必须**由 `DanioNet` 驱动。接线点：`pipeline/arena_episode.py` 已做 `DanioNet` 驱动（`scripts/run_chain.py`）；对外服务层的在线切换仍待随 `api/` 重写落地（对应 `arena/Danio_Arena设计与实现说明.md` §11 与 `api/API接口.md`）。
