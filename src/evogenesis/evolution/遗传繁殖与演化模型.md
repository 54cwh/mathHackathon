## 1. Genome
两对 chromosome pairs；每条 haplotype chromosome 128 bp；diploid total 512 bp。

## 2. Meiosis
每对 chromosome（**recombination 规则见 `genome/生物学与进化遗传学基础.md` §4**，本文件不另立）：
1. 以 0.5 概率发生一次 crossover，crossover point 均匀采样。（**0.5 为每对染色体的交叉概率**：每配子至少一次交叉 \(=1-0.5^2=0.75\)。它是**计算抽象**，不代表真实重组率、也非可调超参——GA 的单点交叉率惯例（0.6–0.9）针对优化问题，不适用。）
2. 随机选择一条 chromosome 进入 gamete。
3. 对 gamete sequence 施加 SNP mutation。

gamete：

\[
256\ bp
\]

## 3. Fertilization
\[
gamete_A+gamete_B\rightarrow offspring

## 4. Mendel Mode
\[
AaBb\times AaBb
\]

A/B 位于不同 chromosome pairs。

展示：
- parent genotype
- gamete classes
- theoretical 9:3:3:1
- 160 simulated offspring
- empirical ratio
- chi-square goodness-of-fit

**基因型 → \((E_A,E_B)\) 映射（定稿）**：定义归 `genome/生物学与进化遗传学基础.md` §3，本文件引用、不另立一版。要点：`A` 位点 ↔ motif 子集 \(K_A\)、`B` 位点 ↔ \(K_B\)（MVP \(k_A=0,k_B=1\)，标签可交换）；\(E_A,E_B\) 各**只在该位点自身染色体对上**计算、两条同源链加性平均（窗口不跨界）。因 \(A,B\) 位于不同染色体对，独立分配使两轴独立，四类计数严格 9:3:3:1。四类判定 `high_N⟺E_A>θ_N`、`high_H⟺E_B>θ_H`（`genome §3`）。

**dominance 的必要条件（可推导）**：在 \(\tfrac12\) 聚合下 \(E_A\in\{1,\,0.5,\,0\}\)（对应 `AA/Aa/aa`）；要 `Aa` 也判 high（完全显性）**必须 \(\theta_N<0.5\)**，同理 \(\theta_H<0.5\)。故**离散 \(E\)** 下须 \(\theta_N,\theta_H\in(0,0.5)\)，否则退化为完全隐性。当前实现 \(E\) 为**连续读出**，阈值按独立校准集每轴中位定为 \(\theta_N=0.67,\theta_H=0.69\)（`genome §3`，2026-09-27），合法区间相应放宽为 \((0,1)\)。

## 5. Natural Selection（选择算子 owner）

**选择算子：binary tournament（\(k=2\)）**。从当代 **viable** 个体中随机取 2 个、比较 \(F\)、取较大者为亲本；重复直至配齐。选择压力**尺度无关**——二进制锦标赛在期望适应度分布上**等价于最大线性排名** `[bib#136]`，且 tournament 对适应度的平移/线性变换不变 `[bib#137]`；相较比例 / softmax 选择（强度与适应度尺度不可分离 `[bib#135]`），更适合小种群与含噪的单 episode 适应度。

**抽样与并列（定稿）**：锦标赛采样**有放回**——从候选池独立抽取 \(k\) 个下标，同一亲本可在同一次锦标赛中重复入选，也可跨次重复入选；\(F\) 并列时取**抽中顺序中先出现的候选**。**为何必须有放回**：锦标赛选择的「尺度无关、等价于最大线性排名」性质（`[bib#136]`）以有放回抽样为前提；无放回抽样会退化为随机交配，抹平选择压力。

**不使用比例 / softmax 选择**（\(\beta\) 不再是参数）。

**候选池（定稿）**：仅当代 `viable=True` 的个体进入亲本池与锦标赛候选；**non-viable 排除**（其 \(F\equiv0\)）。`viable` 但 \(F=0\) 者**仍可入选**——低适应度不等于不可育，`F=0` 本身不作为排除依据。

**锦标赛规模与候选数的关系（定稿）**：若候选数小于 `tournament_size`，一次锦标赛无法组成，`binary_tournament` **抛 `ValueError`**（配置非法，不静默退化、不重复抽满）。

**繁殖规模**：随机配对并产生 **N=48 offspring（出生数恒定）**。non-viable 新生儿计入种群但 `F=0`、不进 Arena（§7）；出生数恒定保持漂变强度可比（`genome §9`）。若当代 viable 个体 \(<2\)（无法配对），记 **`evolution.population_bottleneck`** 事件并判**本次繁殖失败**。该事件是**运行级事件**（由 `evolution` 产出、编排层消费），**不入 Arena 事件流、不属 arena 事件词表**（`core §5` 与本模块各自拥有自己的事件域）。

**随机配对（定稿）**：配齐 \(2N\) 个亲本后，从亲本池**有放回**抽取 \(2N\) 个下标（即上述 \(2N\) 次锦标赛的胜者），整体随机置换，再**相邻两两成对**（第 \(2i\) 与第 \(2i+1\) 个）。**禁自体配对**：置换后逐对修复——若某对内两下标相同，与**其后最近一个不同下标**交换；若其后无不同下标，则与**其前一个能保持配对合法性的下标**交换，多轮至无冲突。**可行性边界**：某个亲本被抽中次数超过 \(N\)（占有放回 \(2N\) 槽位的一半以上）时，自体配对在数学上不可避免；此时退回「按值稳定排序后对半配对」的构造，仅保留**最少数量**（\(m-N\) 个自体配对，\(m\) 为该亲本出现次数且 \(m>N\)）的自体配对。该边界是抽样**有放回**的固有结果，非实现缺陷。**实测（2026-09-26）**：48 个 viable、\(2N=96\) 槽位、200 个 seed 下，无论 \(F\) 全相等、线性递增还是「仅 1 个强优个体」，自体配对均**恒为 0**，单亲本最大被抽中次数 9–12；仅在 viable 少到约 3 且存在强优个体时才被迫自体（最大被抽 67 次 \(>N\)）——该代本身已贴近 `evolution.population_bottleneck`。

**世代更替（定稿）**：世代**不重叠**——当代产生的 N 个 offspring 即下一代种群，亲代不保留；non-viable 新生儿仍计入下一代（`F=0`，不进亲本池）。子代 `genome_id` 由调用方给定的 `experiment_id` 与本代 `generation` 经 `core/ids.py::mint_id(experiment_id, "genome", generation, index)` 铸造（格式 owner 为 `core §3.1`，本模块不另立）。锦标赛采样与随机配对的随机源取 `core §3` 的 `selection` 命名空间（id=6），其实体序号 \(t\) 取**子代世代号** `generation`；配子/突变的随机源沿用 `crossover` / `mutation`（`genome §4/§5`），**每个子代全局独立**派生——\(t = generation \cdot N + index\)（\(N\) = 每代出生数，取自该子代 `genome_id`），由 `genome_id` 确定性解析、不使用调用顺序，跨代不复用（`core §3`）。

**Artificial Selection（定稿，2026-09-27 用户确认）**：用户**无视 fitness** 直接指定亲本、替换锦标赛，形成与自然选择的直接对照（`genome §10`）。接口 `advance_generation(..., forced=None)`，`forced` 二选一：

- `forced_pair=(id_a, id_b)`：该对亲本产**全部 \(N\) 子代**（demo「Parent A × B → Breed」便捷形）；
- `forced_pairs=((id_{a1},id_{b1}),\,…,\,(id_{aN},id_{bN}))`：**逐子代**指定，长度须 \(=N\)。

亲本一律以**稳定 `genome_id`** 指定（禁下标），须存在于当代 `parents` 且 `viable=True`；强制通道**不消费 `selection` 命名空间**（选择已由用户决定），配子/突变仍取 \(t=\text{generation}\cdot N+\text{index}\)（与自然选择同随机流、逐位可复现）；`id_a=id_b`（**自交**）**允许**并如实记录。**回退规则**：id 不在当代 / `viable=False` / `forced_pairs` 长度 \(\neq N\) → 抛 `ValueError`；`forced_pair` 与 `forced_pairs` 同时给出 → 抛 `ValueError`；`forced` 非空时**不判** `evolution.population_bottleneck`。`selection_mode` 记 `"artificial"`，`forced_parent_ids` 记**去重**后的指定亲本（首次出现顺序）。**范围**：本模块提供 L2「选择算子替换」；L1 繁殖原语（`Parent A×B→offspring`）由 api 侧 `POST /v1/breedings`（`genome_lab.breed`，复用 `reproduction.offspring_genome`）提供。

## 6. Fitness
**归一化（定稿）**：\(S/P/E_{\mathrm{esc}}/Q\) 四项各自在**代内 viable 个体**上做 min-max 归一到 \([0,1]\)（与 Q 口径一致）；若某分量当代 `max=min`，该分量置 0（不贡献）。因此 \(F\) 是**代内相对分数**，只用于本代选择与展示；**跨代、跨环境比较一律用原始指标**（`survival_steps` / `captures` / `escapes` / `energy`），不用 \(F\)。权重 \(0.35/0.25/0.20/0.20\) 为**设计选择**，须做敏感度分析。

**与 `experiment` 的边界（定稿）**：选择用的 \(F\) 由本模块产出（四项先在**代内 viable** 上 min-max 再加权）；`experiment/metrics.py` 只产出**原始分量与逐个体显示分**（四项 rate 直接加权，无代内归一），不参与选择。跨代、跨环境比较一律用原始指标。

\[
F=
0.35S+
0.25P+
0.20E_{\mathrm{esc}}+
0.20Q
\]

S=survival，P=prey capture，\(E_{\mathrm{esc}}\)=escape success，Q=energy efficiency。各分量的原始字段与计算式见 `experiment/实验与评价体系.md` §2.1：`S=survival_steps`、`P=captures`、\(E_{\mathrm{esc}}=\)`escape_successes`、`Q=`净能量积累率（下）。

**Q 口径（决策）**：MVP 采用**净能量积累率**的简化式

\[
r_i=\frac{E_i(T_i)-E_{max}}{T_i},\quad T_i=survival\_steps_i
\]

（只用已落盘的 `energy_trajectory` + `survival_steps`，零新参数）。等价定义（`R_{food}/C_{base}/C_{move}` 定稿后启用）为净能量获取率

\[
r_i=\frac{R_{food}\cdot captures_i-\sum_t(C_{base}+C_{move}v_{i,t}^2)}{T_i}
\]

（`[bib#37][bib#43]`）。两者在**无能量上限截断时等价**；截断触发时简化式有偏。归一化用**代内 min-max**（`[bib#23]`），`max=min` 与 cohort 边界须固定。`v^2` 指数为工程选择（文献幂指数 1.1–3.0、阻力基线为 \(v^3\)）。决策原因见 `research/notes/契约决策记录.md`。

## 7. Non-viable

**新生儿初值（定稿）**：繁殖产出的新生儿尚未评估，初值 `viable=False`、`failure_reason=None`、`F=0`；发育/评估后由编排层回填 `viable` / `failure_reason` / `F`（未评估与已判定 non-viable 都以 `viable=False` 表示，由编排层区分）。

违反 viability constraints：

\[
F=0
\]

并记录 failure reason。**选择处置**：**non-viable**（`viable=False`）不进亲本池（§5）；`viable` 但 \(F=0\) 者仍可入选。

行为差但发育成功的个体仍进入 Arena，由 ecology 决定 low fitness。
