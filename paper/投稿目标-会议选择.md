## 2. 推荐（按「中稿可行性 × 匹配度」分层）

**第一顺位：GECCO 2027（CCF-C）**
- NE + EML 两个 track 与本项目**完全对口**；社区对「仿真型 + 生物启发」的接受度远高于 ML 三大会。
- 8 页不含参考文献，够放 baseline（MLP/GRU/Fixed Sparse RNN）+ 消融（w/o GRN、同质 τ）。
- **模板零摩擦**：`acmart.cls` 本机 TeX Live 2026 自带（我实测 FOUND）。
- 截稿：**2027-01-19 摘要 / 2027-01-26 全文**（GECCO 2027，Kraków，7/12–16）。

**第二顺位：IEEE TEVC（CCF-B 期刊，最对口期刊）**
- 神经演化 + NAS 的**最对口去处**，**无页数压力** —— 这是把完整消融矩阵与
  「genomic bottleneck 阻止 ΔW 遗传」这套机制论证写透的唯一场所（8 页会议放不下）。
- 滚动投稿，无截稿焦虑；适合「会议先发一版、期刊发完整版」。

**第三顺位：ALIFE 2027（无 CCF 等级，但领域母语）**
- 发育式编码、6 类细胞先验、Dale 约束 —— ALIFE 审稿人**天生就懂**，不必为 ML 审稿人做概念铺垫。
- 单盲、3–8 页弹性、MIT Press 开放获取；**最容易过**。
- 代价：**对国内考核/评奖不加分**。若目标是「有 CCF 抬头的成果」，只能作为并行/补充（注意一稿多投政策）。

**跳一跳：ICML 2027（CCF-A，约 2027-01 截稿）或 AAAI-28（约 2027-07/08）**
- 前提是**重构叙事**：把「发育式编码」讲成一个可被 ML 社区检验的**方法贡献**
  （如 genomic bottleneck 作为隐式正则 / 抗过拟合机制，配 NAS benchmark 对照）。
- IJCAI 2027（现 CCF-B，约 2027-01）是**本次目录变动的红利**，难度低于 A 类。

## 4. 中文草稿 → 英文定稿的工作流（**关键风险**）

**所有 ML/EC 顶会官方 sty 都是英文单语设计，不支持中文。**

| 阶段 | 做法 |
|---|---|
| **中文草稿（当前）** | `ctexart` + XeLaTeX（本仓已就绪，`paper/latex/`）；单栏、页数上限按「每页 ≈550–650 中文字 ≈ 双栏 10pt 英文一页」折算，避免定稿时大幅删改。 |
| **定稿转英文** | 套官方 sty。**注意**：AAAI/NeurIPS/ICML/ICLR 的 sty **明文禁止改版式参数**（AAAI 原文：「YOU MAY NOT MODIFY IT FOR ANY REASON…WILL RESULT IN REJECTION」），且带自检宏。**不要在这些 sty 上强行 `ctex`/`xeCJK` 中英混排**；先转纯英文再套 sty。 |
| **可中英混排的例外** | `acmart` / `IEEEtran` / `llncs` / `alifeconf` 是标准类，可配 xelatex + xeCJK 做中英混排（`llncs` + ctex 是 Springer 中文稿常见组合）。 |

编译引擎：中文与混排 → **XeLaTeX**；会议官方 sty 英文定稿 → **pdfLaTeX**。
