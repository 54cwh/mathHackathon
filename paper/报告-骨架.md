## 0. 写作主轴（不是章节，是判据）

赛题补充说明（Tier 0 外部硬约束）把评审关注点写死为四问：

> **为什么要改 → 改了什么 → 实际结果如何 → 具有什么价值与意义**

补充说明里另有四条硬约束，直接决定本报告结构：

| 补充说明 | 原文要点 | 对本报告的约束 |
|---|---|---|
| （二）架构设计应具有实际验证 | 不应停留在架构图/概念；**应形成「原模型 → 修改后模型 → 实验结果对比」** | **必须**有 baseline 对照表；本报告第 4/5 章的主轴 |
| （三）模型复杂度 ≠ 创新性 | 不会因规模大/模块多/名词复杂而认定创新；要说清「为什么改、解决了什么」 | 第 2 章每个设计选择必须带**理由 + 代价**，不堆术语 |
| （四）成果展示不应只有指标表 | 鼓励图表、可视化、典型案例、**动态演示**；关注「改之前什么效果、改之后什么变化」 | 第 5 章以**图**为主、表为辅；第 6 章接 Demo |

| （六）论文篇幅不作为依据 | 长/公式多/图多不加分 | 全文压到「最短能讲清四问」；删装饰性章节 |

## 2. 方法：改了什么（What）

> 写法要求（对应补充说明三）：每个设计选择写**三行** —— 选择 / 理由 / 代价或边界。

### 2.1 网络结构 DanioNet

| 设计选择 | 取值 | 理由 | 代价 / 边界 |
|---|---|---|---|
| 神经元功能类 | 6 类 | 抽象自斑马鱼感觉运动回路 `[bib#6][bib#7]` | 真实细胞类型远超 6 类 `[bib#84]` |
| 神经动力学 | 漏积分发放（离散） | TODO | TODO |
| 输入 | 12 维 `[0,1] float32` | 冻结契约（`DanioNet设计规范.md` §2） | `looming_rate` 当前实现缺口（恒 0） |
| 动作 | 连续 `(ω,v)`，均值池化 | 池大小不变、零新参数 | TODO |
| 左右竞争 | motor 按发育 x 中位数二分 | TODO | TODO |
| 可训练对象 | 仅 `Θ`（与 W⁰ 同形） | 支撑冻结、不新增连接 | 支撑不变 ⇒ 结构不可在当代改变 |

- **实测结构规模**：**凭证 = `scripts/probe_architecture.py` → `results/tables/architecture_probe.json`**
  （`results/**` 不入库、可重生成）。探针口径：seeds `[1103, 2207, 3301]` × 每 seed 14 个体 = 42 个体，
  固定 `configs/default_model.yaml`（sha256 `dc70f7f864e3…`）；产物自带 `digest`（内容 sha256），
  **同一入参两次运行逐字节相同**（`tests/test_probe_architecture.py` 钉住）。
  ⚠️ **结构尺寸在个体间方差很大，引用必须并列分布**（只报一个数会让人误以为架构固定）：

  | 量（括号内为理论上界） | min | median | mean | max |
  |---|---|---|---|---|
  | 神经元数 `N`（≤ 48） | 26 | 36 | 35.76 | 44 |
  | 支撑连接数（≤ N(N−1)） | 94 | 186 | 187.17 | 287 |
  | 支撑密度 | 0.1290 | 0.1484 | 0.1481 | 0.1667 |

  六类 cell type 计数的**中位数均为 6**（均值 sensory 6.02 / prey 6.26 / threat 6.26 /
  integrator_memory 5.62 / inhibitory 5.69 / motor 5.90）——六域近似均匀，反映
  「每域等量前体（`precursors_per_domain: 4`）且分裂过程同分布」这一发育机制，
  **不是**固定的手写常数（逐个体的计数在 0–25 之间波动）。
  左右 motor 池大小的中位数为 **3 / 3**；按 ``DanioNet设计规范.md`` §5 的中位数二分
  （「低于中位者标 left」，实现取 `left_count = |motor| // 2`），恒有 `left ≤ right`
  且差值 ∈ {0, 1}（42 个体中 52.4% 恰好相等、31.0% 恰为 3/3）。
- **可训练参数量**：`Θ` 张量形状 `(1, 48, 48)` = **2304 元素/个体**（batch 内 padding 到
  `development.max_neurons` = 48），**有效可训练 = 支撑 `A` 内的元素数，与支撑连接数同源**
  （probe 逐个体断言二者相等；中位数 186，个体间 94–287）
  → 供 §8「同一数量级」判据 `|log10(N_base) − log10(186)| ≤ 1` 使用，即 baseline 可取 19–1860。
- **发育通过率（随机 q）**：**2/14 ≈ 14%** —— 说明发育是强约束筛选；报告需解释这为何是特性而非缺陷。
