## 2. 前端实际调用清单（WS）

### 2.1 结论：**WS 在前端是「零调用」的休眠契约**

`frontend/src/api/ws.ts` 只做两件事：
- `WsEnvelope<T> = { v: 1; type: string; seq: number; ts: number; payload: T }`（`ws.ts:1-7`）
- `connectWs(path = "/v1/ws")`：按 `location.protocol === "https:"` 选 `wss`/`ws`，拼 `${protocol}://${location.host}${path}` 后 `new WebSocket(...)`（`ws.ts:9-12`）

**`connectWs` 在全仓 `frontend/src` 中没有任何 import 或调用点** —— 唯二的 grep 命中就是它自己的定义行（`ws.ts:1`、`ws.ts:9`）。因此：

| 侦察项 | 事实 |
|---|---|
| 连接路径 | `/v1/ws`（默认参数，`ws.ts:9`），但**从未发起连接** |
| 信封字段 | 前端**期待** `{v:1, type, seq, ts, payload}`（`ws.ts:1-7`），对应 R11（`API与系统工程.md:70`） |
| 前端期望收到的 `type` | **代码中硬编码 0 个**；`types.ts` 与各 panel 亦无 `arena.fish_state` 等字面量 |
| 前端发送的消息 | **无**（无 `send()` 调用点） |
| 降级逻辑 | **无**（未连接即无需降级） |

### 2.2 文档侧的 `type` 词表（重写须落地的口径）

| 来源 | `type` | 文档地位 |
|---|---|---|
| `API与系统工程.md:70`（R11 举例） | `arena.fish_state`、`brain.activation`、`job.progress`、`sys.error` | **举例**，非完整词表（该文 §阅读问题 5 自认"词表不完整"） |
| `API接口.md:234-236` | `sys.hello`、`sys.echo`、`sys.error` | 历史上是**唯一实现**的三条；`sys.echo` 去留待认领（`API接口.md:452` B5） |
| `API接口.md:237` | `arena.*` / `brain.*` / `job.*` | 标为**未实现**；§8.2（`:379-394`）逐项列出 5 类业务推送（fish transforms / 神经激活 / energy / events / generation progress）**全部缺失** |
| `API与系统工程.md:100-110`（§5 目标清单） | 语义层：fish transforms、selected-fish neural activation、energy、events、generation progress | 目标，未实现 |

**计数**：前端硬编码期望 `type` = **0**；文档口径 = **3**（`sys.hello`/`sys.echo`/`sys.error`）+ **4**（R11 举例）= 7 个具名字面量，其余为通配（`arena.*`/`brain.*`/`job.*`）。

## 6. 会失效的前端假设

> 按"重写后是否会导致前端报错/静默错误"排序，**前 3 条是硬崩**。

| # | 前端假设 | 证据 | 重写后被破坏的后果 |
|---|---|---|---|
| **1** | **`snapshot` 必有 `prey`/`predators`/`obstacles` 三个键** | `DanioArenaPanel.tsx:118`（`for (const o of snap.obstacles)`）、`:127`（`Object.values(snap.prey)`）、`:135`（`Object.values(snap.predators)`）—— **无 `undefined` 保护** | 若照 `API接口.md:144-151` 只实现 `fish`+`events`：`snap.obstacles` 为 `undefined` → `for...of` 抛 **TypeError** → 整个渲染 `useEffect` 炸掉，画布全黑。**这是文档缺口 G5 的直接后果** |
| **2** | **`DELETE` 必须返回 204 且无体** | `arena.ts:74-75`；调用点 `DanioArenaPanel.tsx:53,65` | 若返回 `200` 而体为空：`res.status !== 204` → 走 `res.json()` → **空体解析抛错**。因外层是 `.catch(() => undefined)`，表现为**静默失败**（会话泄漏，不报错） |
| **3** | **`release` 同步推进并回 `SessionSummary`** | `DanioArenaPanel.tsx:79,83-90` | 若改成 `202 + job_id`（`API与系统工程.md:98` 的异步风格，或 B1 认领后改语义）：`summary.generation` 等**全 `undefined`** → 头部统计退化为 `Generation 0` / `Fish —` / `Seed —`（`App.tsx:22-37` 的 `?? 0` / `—` 兜底掩盖了错误），且 `step` 不再前进（`s.step` 恒 0） |
