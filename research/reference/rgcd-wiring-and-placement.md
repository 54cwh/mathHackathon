## 问 1：gene-expression 相似度作为布线项

### 文献支持的形式：双线性

Qiao 2024（eLife）把推荐系统的双线性模型迁移到转录组→连接组：

```
预测连接 = X̂ Â (Ŷ B̂)^T = X̂ (Â B̂^T) Ŷ^T        (Qiao 2024, Eq.1/4/13)
```

令 `M = Â B̂^T`（低秩 `d≈2`），即 **`R = g_i^T M g_j`**。Kovács 2020（PNAS）的 Spatial Connectome Model 用对称共享规则矩阵：`B = X O X^T`。两者是同一双线性族。Sanes & Zipursky 2020 说明识别分子是**异源相互作用**，所以 `M` 允许非对角（不必是 `I`）。

### 为什么推荐中心化 + 归一

- 未归一化的 `g_i^T g_j`（`g∈[0,1]^k`）取值 `∈[0,k]`，量级随维度线性增长，无法与 `z_i^T C z_j`、`λd` 配平。
- 负欧氏距离经展开 `‖g_i-g_j‖² = ‖g_i‖²+‖g_j‖²-2g_i^T g_j`，仅在 `‖g_i‖≈‖g_j‖` 时与内积单调等价；因此**余弦/归一化内积比负距离更稳健**，文献也不支持把 `-‖·‖` 当独立推荐形式。
- 推荐：`ĝ=(g-ḡ)⊙σ̂^{-1}`，`R=ĝ_i^T M ĝ_j/k`，`M=I ⇒ R∈[-1,1]`（即中心化余弦=Pearson 相关）。

### 量级与 γ

`γ` 初值 1.0，搜索 `{0.5,1,2}`，使 `γR` 典型贡献 ≤1–2 个 logit 单位（与 `z^T C z∈[-2,2]` 可比）。`γ`、`b_A` 联合校准，约束 density 10%–20%。

### 关键反例与边界（必须写进论文）

| 证据 | 结论 |
|---|---|
| **Caron 2013** Nature：~200 个 Kenyon 细胞无一共享相同肾小球输入组合 | 单神经元层级布线有强随机性 |
| **Hayashi 2022** Curr Biol：蘑菇体输入连接在感觉活动缺失下仍形成 | **反对 Hebbian/活动依赖**默认假设 |
| **Qiao 2024**：C. elegans 仅 innexin 预测电突触 **AUC≈0.6435**（随机=0.5） | 表达→连接解释力**有限**；`R` 宜作弱偏置项 |
| **Kurmangaliyev 2019**：轴突/树突布线由**分离**的转录模块定义 | 单一 `g_i^T g_j` 无法表达模块分离 |

**诚实结论**：文献支持双线性的**函数形式**，但不提供「作为加性 logit 项、量级 O(1)」的标定值；`γ` 属本项目标定量。应把 `R` 定位为表达相容性偏置，而非主预测器。

## 问 2：前体空间放置与 λ 标定

### 放置分布：随机 placement 有强证据

- **Hill 2012（PNAS）**：298 个新皮层细胞**独立随机放置**，由此产生的轴突-树突统计重叠**足以复现特异功能连接**。→ 直接支持 `p_i~U(域)`。
- **Rosenbaum 2016（Nat Neurosci）**：神经元置于**单位正方形**，连接概率随距离衰减，距离**以域边长归一**。→ 坐标归一范式。
- **HyperNEAT / ES-HyperNEAT**：规则 substrate 网格是 neuroevolution 工程惯例。→ 规则网格**仅作参考**（工程传统，非生物机制）。
- **Wolpert 1969；Kicheva & Briscoe 2023**：morphogen/位置信息驱动 domain 模式。→ 支持 domain-blocked 放置的生物学动机。

**推荐**：`domain-blocked uniform`——每个 domain 一个分区中心，`p_i = c_block + U([0,1]²)·w_block`；兼顾「随机（Hill）」与「解剖先验（Wolpert）」。

### λ 的量纲标定

`σ(z^T C z − λd + …)` 中 `λ` 量纲为 `1/长度`。两个尺度陷阱：

1. **不能照搬猕猴 `λ=0.188 mm^-1`**（Ercsey-Ravasz 2013），本项目坐标无量纲。
2. 必须先归一：`λ = c / L_char`，`L_char = max(Lx,Ly)`，`c∈[1,3]`，默认 `λ_unit=2`。

单位方域内 `d∈[0,√2]`，`E[d]≈0.521`。`λ=2` 时平均距离处 `λd≈1.04` logit 单位，远距离（`d≈1.4`）≈2.8，近邻（`d≈0.1`）≈0.2。

密度反解：

```
b_A = logit(p_target) − E[z^T C z] + λ·E[d] − γ·E[R],   p_target∈[0.10,0.20]
```

Arena 若为 100×60 且**不归一**，则 `λ_raw ≈ 2/100 = 0.02`。

**风险**：`λ`、`b_A`、`γ` 三耦合；单独调 `λ` 会改变密度。必须在报告中给出 `(λ, b_A, γ, 实测 density)` 四元组。

## 问 3：递归 GRN 初始化与不爆炸

### 推荐

1. `W_g` 先按 **Glorot/Xavier**：`Var(w)=2/(n_in+n_out)`（等价 `W_g~N(0,1/n_g)`）。
2. 再重标定谱半径：`W_g ← W_g·ρ_target/ρ(W_g)`，`ρ_target≈0.9`（保守 0.8；欲取混沌边缘则 0.95–1.0）。
3. 非递归权重 `B, P, U, u` 用 Xavier；偏置 `b, b_w, c ~ N(0,0.1)` 防 sigmoid 饱和。

### 不爆炸论证（本项目专用）

GRN 步 `g^{r+1}=(1-ρ_g)g^r + ρ_g σ(W_g g^r + …)`，Jacobian `J=(1-ρ_g)I + ρ_g W_g diag(σ')`：

```
‖J‖ ≤ (1-ρ_g) + ρ_g·ρ(W_g)·max σ'
```

- 本项目 **sigmoid**（`max σ'=0.25`）+ **`ρ_g=0.35`**：`‖J‖ ≤ 0.65 + 0.0875·ρ(W_g)`，只要 `ρ(W_g)<4` 即收缩。
- 若改用 **tanh**（`max σ'=1`）：`‖J‖ ≤ 0.65 + 0.35·ρ(W_g)`，要求 `ρ(W_g)<1`。

**诊断**：每次 run 记录 `ρ(W_g)`、`‖g‖` 轨迹、饱和率（`|g|<0.01` 或 `>0.99` 占比），作为 §7 dynamical viability 的可量化判据（补阅读问题 #8）。

### 诚实边界

- 「谱半径 <1 ⇒ ESP」是**经验充分条件**，Yildiz, Jaeger & Kiebel 2012 给出反例；论文中写成「稳定性启发式」，不要写成定理。
- 真正的饱和风险来自输入偏置项，初始化只是必要条件。
- 未找到专为「阻尼 sigmoid 迭代 GRN」建立初始化惯例的权威文献；Glorot+谱半径是从通用递归网络迁移，需本项目最小实验验证。

## 需要拍板的开放点

1. `M` 取 `I`（零额外参数）还是低秩可学习 `M=AB^T`（更贴文献，但 MVP 要决定是否训练）。
2. `g_i` 是否中心化/z-score（会改变 §4 g 的语义，需回写文档）。
3. `γ` 固定常数 vs 写入基因组由演化调节。
4. `p_i`：全域均匀 / domain-blocked / 规则网格（影响 λ 标定）。
5. 计算 `d` 前是否把坐标归一到 `[0,1]²`（决定 λ≈2 还是 ≈0.02）。
6. 是否把 `R` 纳入主模型：鉴于 AUC≈0.64，建议弱偏置定位并如实报告其单独预测力。
