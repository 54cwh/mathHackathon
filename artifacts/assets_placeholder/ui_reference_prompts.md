> 用途：为 `frontend/交互与可视化.md` §1 那句「最终视觉主题等待参考图后冻结」提供可执行的参考图生成方案。
> 生成工具：ChatGPT 内置生图（GPT Image 2）。
> 模板来源：`freestylefly/awesome-gpt-image-2` → `ui-screenshot-system`（Category: UI & Interfaces）。

## 变更记录

- **2026-09-26 修订**：视觉方向改为**像素质感**（16 位农场 / 沙盒游戏一类气质）。此前暗色系三变体按辰钊要求作废，已移除。
- 同时修正两处路径引用：`docs/design/08_交互与可视化.md` → `frontend/交互与可视化.md`；`docs/design/17_验收清单.md` → `docs/验收清单.md`（`docs/design/` 已于 `a8ded6d` 归位，原路径不再存在）。

## 使用前提（红线不变）

依据本项目 `frontend/交互与可视化.md` §12 与 `artifacts/assets_placeholder/image_prompt_template.md`：

- 生成的图**只能当作视觉方向参考**，用于确定配色、密度、层级、质感。
- **不得**作为界面截图放入答辩稿或论文——它看起来像真实界面，会被读作伪 data。
- 提示词中所有图表区一律要求「抽象占位、无可读数值」。
- **不得复制任何商业游戏的角色、道具、场景或界面元素**（`image_prompt_template.md` 明写「不复制商业游戏角色」）。下述提示词只借用像素美术的**通用质感语言**，不指向任何具体作品资产。

## 提示词 1 —— 整台界面像素质感（主诉求）

**定调理由**：直接对应「像素风实验台」。明亮、饱和、有限调色板，俯视视角，接近 16 位农场模拟游戏的暖色自然调。

```text
生成一张 16:9 桌面端 Web 应用的完整界面截图，一个名为 EvoGenesis 的生命演化实验台，整体采用 16 位像素艺术风格。

像素风格要求：手工逐像素绘制的质感，所有边缘是清晰的方形像素块，完全没有抗锯齿和平滑过渡。使用受限调色板，整幅画面不超过 32 种颜色，通过抖动点阵来表现过渡。所有线条粗细统一为 1 像素或 2 像素。整体气质接近 90 年代 16 位农场模拟游戏和沙盒游戏的明亮自然调，但不要复制任何具体游戏的角色或界面元素。

布局分三层：
1) 顶部状态栏：一条像素风横条，用带斜角高光和暗部的像素边框包裹。左端是产品名 EvoGenesis，用点阵像素字体。右端横向排列六个状态项，分别是 Env、Generation、Fish、Prey、Step、Seed，每项由一个像素小图标和一个点阵数字组成。
2) 主体区等宽三栏，栏目之间用 2 像素宽的像素分割线隔开：
   - 左栏 DNA2Brain Lab：上半部是一段立体的像素双螺旋 DNA，用明快的糖果色像素块拼成，带复古游戏道具的质感；下半部是一条扁平的 ACGT 碱基序列带，四个字母用点阵像素字体横向排布，其中一个字母被像素高亮框选中，旁边有一枚小的像素三角标记。
   - 中栏 Brain Forge：一张像素风格的神经网络发育示意，节点是小型像素方块，连接边是 1 像素细线，网络从左上向右下由稀疏变密集，不同细胞类型用三种高区分度的像素色标注，整体像游戏里的技能树或科技树面板。
   - 右栏 Danio Arena：俯视的像素水池竞技场，水面用蓝绿像素块配合抖动点阵表现波纹，池边是草地和石块的像素瓦片。水中有几条细长的像素斑马鱼（深色身体带浅色条纹，横向游动）、几个更小的猎物像素点、一个明显更大的捕食者像素轮廓，以及几个方形像素障碍块。
3) 底部控制栏：一条细像素横条，左端两个像素风按钮——**主按钮**（运行中显示 Pause、停止时显示 Release）与 **Reset**——带明显的像素立体边框和按下感，右端一行小号点阵灰色文字 Evolution / Experiment / Playback。

配色：明快的自然色系——草绿、木棕、天空蓝、暖黄、珊瑚橙作为主色群，深色仅用于描边和阴影，不用于大面积背景。背景整体明亮。

文字要求：所有界面标签使用点阵像素字体，英文单词拼写正确、清晰可读。

分辨率 16:9，高清但保持像素边缘锐利，不要模糊，不要插值放大造成的柔化。

负面要求：不要抗锯齿，不要平滑渐变，不要柔和阴影，不要玻璃拟态，不要现代扁平化 UI，不要三维渲染，不要写实材质，不要暗色调，不要赛博朋克霓虹，不要任何具体数值读数，不要伪造的统计图表，不要复制任何现有游戏的具体角色或界面。
```

## 提示词 2 —— 素材包：像素 sprite sheet

**定调理由**：这是**最容易落地、风险最低**的一档，且与项目 `image_prompt_template.md` 预留的三类素材（Fish sprite / Predator / DNA）精确对接。UI 框架不动，只把游戏内对象像素化。

```text
生成一张像素艺术素材表（sprite sheet），纯白背景，所有素材整齐网格排列，每个素材之间留出均匀间隔，不带任何文字标注。

风格要求：16 位像素质感，逐像素手工绘制，边缘为清晰方形像素块，无抗锯齿，受限调色板，用抖动点阵表现明暗过渡。整体是明亮的自然色系，气质接近 90 年代俯视农场与沙盒游戏的素材集，但为原创设计，不复制任何现有游戏的角色或道具。

需要包含以下素材，每个方向一个独立 sprite：
1) 斑马鱼 sprite，五个朝向（上、下、左、右、斜向），细长流线型身体，深色身体配浅色横向条纹，俯视视角，轮廓清晰，在极小尺寸下仍能辨认。一共五枚。
2) 幼鱼 sprite，与成鱼同一造型但尺寸明显更小、体色更浅，三枚朝向。
3) 猎物 sprite，小型圆润的像素生物，明亮的暖色调，两枚朝向，体型明显小于鱼。
4) 捕食者 sprite，比鱼大得多、形态更具压迫感的像素水生物，暗色调配锐利轮廓，两枚朝向。危险层级要一眼可辨，但不要像任何商业游戏中的既有角色。
5) DNA 双螺旋 sprite，一段短的双螺旋结构，用糖果色像素块拼成，三枚不同旋转相位。
6) 碱基图标四枚，分别代表 A、C、G、T，用四种高区分度颜色的小型像素符号。
7) 环境瓦片：水面、深水、草地、石块、沙地，各一枚，尺寸统一，边缘可无缝拼接。

所有素材使用同一套调色板，风格统一，可在深色和浅色背景上都能辨识。

负面要求：不要抗锯齿，不要渐变，不要柔和阴影，不要三维渲染，不要写实，不要文字或水印，不要背景场景，不要复制任何现有游戏的具体角色。
```

## 提示词 3 —— 分区混合（工程上最稳）

**定调理由**：竞技场拿像素游戏感，数据区保持专业可读。这是像素风与「9 项指标的 Dashboard、13 字段的 Fish Card、精确的 ACGT 序列」共存时唯一不牺牲功能的做法。

```text
生成一张 16:9 桌面端 Web 应用的完整界面截图，一个名为 EvoGenesis 的生命演化实验台。界面采用分区风格：游戏化的区域用像素质感，数据密集的区域用精密的现代界面，两者通过统一的调色板衔接。

布局为顶部状态栏 + 等宽三栏主体 + 底部控制栏。

像素风区域（右侧 Danio Arena）：这一栏完全是 16 位像素游戏画面，俯视视角的水池竞技场。水面用蓝绿像素块配合抖动点阵，池边是草地和石块的像素瓦片，水中有细长的像素斑马鱼、更小的猎物像素点、一个明显更大的捕食者轮廓和几个方形像素障碍块。边缘是带斜角高光的像素边框。

精密界面区域（左侧 DNA2Brain Lab 与中间 Brain Forge）：这两栏使用干净的现代科学软件界面。左栏上半部是线条精确的 3D DNA 双螺旋，下半部是等宽字体排布的 ACGT 碱基序列带，其中一处被选中框高亮；中栏是精确绘制的神经元网络发育图，节点与边用细线清晰绘制，不同细胞类型用高区分度实色标注。这两栏不使用像素字体，边缘锐利、层级清楚。

顶部状态栏与底部控制栏：使用像素风的边框和按钮，但其中的数值用等宽字体，保证可读。顶部六项为 Env、Generation、Fish、Prey、Step、Seed，底部左端为主按钮（显示 Pause，或停止态下的 Release）与 Reset 两个像素按钮，右端是灰色小字 Evolution / Experiment / Playback。

衔接方式：整个界面共享一套明亮调色板——草绿、木棕、天空蓝、暖黄为主色群，深浅仅用于分层。像素区与精密区通过相同的分割线粗细、相同的圆角处理、相同的色板达成统一，不做突兀拼接。

分辨率 16:9，高清。像素区保持锐利像素边缘，精密区保持干净矢量感。

负面要求：不要暗色背景，不要抗锯齿的伪像素，不要渐变，不要玻璃拟态，不要三维渲染，不要任何具体数值读数，不要伪造统计图表，不要复制任何现有游戏的具体角色或界面。
```

## 生成后自检清单

对照 `docs/验收清单.md` 的 Demo 部分与 `frontend/交互与可视化.md` §12：

- [ ] 三栏是否清晰可辨，且左中右内容对得上 DNA2Brain / Brain Forge / Danio Arena
- [ ] 顶部六项状态是否完整出现
- [ ] 底栏 Pause / Reset 是否在位
- [ ] 像素是否真的是方形硬边（不是被抗锯齿柔化过的「伪像素」）
- [ ] 点阵字体下的英文标签是否仍然可读
- [ ] 是否**没有**出现具体数值、曲线或统计图（红线）
- [ ] 是否**没有**与任何现有游戏资产雷同的角色或界面（红线）
- [ ] 若选了提示词 3，像素区与精密区的衔接是否自然

## 三个必须先解决的工程约束（像素风落地时的真实障碍）

1. **Cytoscape 与 ECharts 不原生支持像素风。** 前者画 Brain Forge 的神经网络，后者画 Evolution Dashboard 的 9 项指标。它们输出标准矢量 / Canvas 图表，要像素化只能靠改配置（限定色板、关闭抗锯齿、方形端点）或改用手绘 Canvas，成本不低。
2. **点阵像素字体在中文与小字号下可读性差。** `frontend/交互与可视化.md` 要求 Dashboard 有 9 项指标、Fish Card 有 13 个字段。像素字体适合英文标签，不适合承载密集数据。建议像素字体只用于导航与标签，数值一律走等宽字体。
3. **现有 token 需要整体重做。** `frontend/src/index.css` 目前是一套暗色 HSL 变量，改像素风且指明快配色，等于配色系统推倒重来，不是增量修改。

## 两处与代码对齐的校正（2026-09-26）

1. **底栏主按钮不是固定的「Pause」**：`App.tsx` 里按钮文案随状态变——运行中显示 `Pause`、停止态显示
   `Release`。提示词 1 / 3 已按此改（原来写死 Pause，会让生成的参考图与真实界面不一致）。
2. **顶栏 6 项以代码为准**：`App.tsx` 实际渲染 `Env / Generation / Fish / Prey / Step / Seed`（6 项）；
   而 `frontend/交互与可视化.md` §1 的 ASCII 草图写的是 `Env | Generation | Population | Seed`（4 项）——
   **草图已过期**，提示词 1 的 6 项与代码一致，无需改。

## ⚠️ 一处必须知道的口径：DNA 面板的参考图是「目标观感」，不是「要切的素材」

3D DNA 已于 2026-09-26 定为 **three.js / @react-three/fiber 程序化渲染**（见 `frontend/README.md` 技术栈），
**不是**一张贴图。所以：

- 提示词 1 / 3 里那条「立体的像素双螺旋」是**目标观感**（用于定配色、密度、层次），
  **不要**把它当成 sprite 去切图使用；
- 真正要生成给 3D 用的是**可平铺的 DNA 纹理 / 碱基符号条**（见 `asset_prompts.md` B1），
  它们会被贴在程序化几何体上。
- 同理，中栏 Brain Forge 的神经网络也是**数据驱动渲染**（Cytoscape，库已装），
  参考图里的网络只是观感参考，不是素材。
