# UI 视觉参考图提示词（GPT Image 2 / ChatGPT 用）

> 用途：为 `frontend/交互与可视化.md` §1 那句「最终视觉主题等待参考图后冻结」提供可执行的参考图生成方案。
> 生成工具：ChatGPT 内置生图（GPT Image 2）。
> 模板来源：`freestylefly/awesome-gpt-image-2` → `ui-screenshot-system`（Category: UI & Interfaces）。

## 使用前提（务必先读）

依据本项目 `08_交互与可视化.md` §12 与 `artifacts/assets_placeholder/image_prompt_template.md`：

- 生成的图**只能当作视觉方向参考**，用于确定配色、密度、层级、质感。
- **不得**作为界面截图放入答辩稿或论文——它看起来像真实界面，会被读作伪 data。
- 提示词中所有图表区一律要求「抽象占位、无可读数值」，避免生成伪 metrics。

## 变体 A —— 暗色科研仪器风（推荐首选）

**定调理由**：契合「实验台」的功能定位，与现有 `index.css` 的暗色基底同向，改动成本最低。走 Industrial / utilitarian 方向。

```text
生成一张桌面端 Web 应用的完整界面截图，一个名为 EvoGenesis 的「数字生命演化实验台」。这不是移动端，是 16:9 桌面浏览器中运行的科研工作台。

整体布局严格分三层：
1) 顶部状态栏，一条细横条，左侧是产品名 EvoGenesis，右侧并排六个状态项，分别是 Env、Generation、Fish、Prey、Step、Seed，每项由一个灰色标签和一个亮色数值组成。
2) 主体区，等宽三栏，栏与栏之间有细分割线：
   - 左栏 DNA2Brain Lab：上半部是 3D 双螺旋 DNA 分子渲染，轮廓清晰、有深度感，深色背景上带冷色自发光边缘；下半部是 2D 碱基序列条，横向排列 ACGT 字母，序列中有一个高亮光标位置和一枚小型变异标记。
   - 中栏 Brain Forge：一张神经元网络发育示意图，节点为细小圆点、边为细线，网络从左上到右下逐渐由稀疏变密集，局部用颜色区分不同细胞类型，整体像一张发育过程的分帧图。
   - 右栏 Danio Arena：一个俯视 2D 水池竞技场，背景是深色水面，里面有若干条细长的斑马鱼造型（横向、深色身体带浅色条纹）、几个较小的猎物点、一个明显更大的捕食者轮廓、几个几何障碍块。
3) 底部控制栏，一条细横条，左端并排两个按钮，分别是 Pause 和 Reset，右端是一行小号灰色说明文字 Evolution / Experiment / Playback。

视觉风格：暗色科研仪器风。底色是接近黑的深蓝灰，面板之间仅靠 1px 细边框分层、不使用卡片阴影。主色是一种克制的青绿色，只用于关键数值、激活状态和少量强调元素，用量不超过整个画面的 10%。字体是现代无衬线体，数值使用等宽字体。图标为极细线条风格。整体克制、精密、信息密度高，像专业科学软件的仪表台，不追求炫目。

文字要求：所有界面标签必须是清晰可读、拼写正确的英文单词，字号足够辨认。不要出现乱码或假文字。

分辨率 16:9，高清，界面边缘平整，无四周留白之外的装饰。

负面要求：不要紫色渐变，不要玻璃拟态，不要大面积发光霓虹，不要卡片圆角堆叠，不要居中大标题 hero 区，不要营销页式的宣传语，不要任何具体的数值读数，不要伪造的统计图表或曲线。
```

## 变体 B —— 暗色生物发光风

**定调理由**：突出斑马鱼与生命演化的主题气质，视觉记忆点更强，适合路演时「让人问这是怎么做出来的」。代价是偏离现有 token 较远，前端改动量更大。

```text
生成一张 16:9 桌面端 Web 应用的完整界面截图，一个名为 EvoGenesis 的「数字生命演化实验台」，整体沉浸在深色生物荧光氛围中。

布局为顶部状态栏 + 等宽三栏主体 + 底部控制栏：
顶部状态栏左端是产品名 EvoGenesis，右端横向排列六项状态标签 Env、Generation、Fish、Prey、Step、Seed。
左栏 DNA2Brain Lab：上半部是一段立体 DNA 双螺旋，螺旋骨架在深色中带冷青色自发光，碱基对呈现为细密的光点；下半部是扁平的 ACGT 碱基序列条，序列以等宽字体横向排布，其中一处被高亮框选中，旁边有一枚小型三角标记表示变异位点。
中栏 Brain Forge：一片正在生长的神经元网络，节点像微小的发光细胞体，连接边是细的浅青色光线，网络从一角向另一角蔓延生长，不同细胞类型用不同色温区分（冷青、浅紫、暖白三种）。
右栏 Danio Arena：俯视的深色水域，水中漂浮几条细长斑马鱼剪影，身体带浅色条纹与微弱生物荧光轮廓，另有几个更小的猎物光点和一团明显更大的捕食者暗影，水域中散布几何障碍块。
底部控制栏：左端是 Pause 与 Reset 两个按钮，右端是灰色小字 Evolution / Experiment / Playback。

视觉风格：深色生物发光科研界面。底色为深墨蓝，接近黑但保留蓝色倾向；光只出现在主体对象上，界面框架保持低亮度。主色是生物荧光青与少量浅紫，强调色克制。字体为现代无衬线体配等宽数字，图标为极细线条。质感冷静、精密，带轻微实验室氛围，避免科幻感与游戏感。

文字要求：所有界面标签使用清晰可读、拼写正确的英文单词。

负面要求：不要赛博朋克霓虹雨，不要紫蓝渐变背景，不要玻璃拟态卡片，不要三维游戏 HUD 风格，不要营销页布局，不要任何具体数值或伪造数据图表。
```

## 变体 C —— 亮色论文版式风

**定调理由**：若参考图同时要用于论文插图或 PPT 排版，需要一个浅色变体。走 Editorial / Swiss 方向。

```text
生成一张 16:9 桌面端 Web 应用的完整界面截图，一个名为 EvoGenesis 的生命演化实验台，采用浅色学术出版物式排版。

布局为顶部状态栏 + 等宽三栏主体 + 底部控制栏：
顶部状态栏左侧是产品名 EvoGenesis，右侧横向排列六项状态 Env、Generation、Fish、Prey、Step、Seed，标签与数值成对。
左栏 DNA2Brain Lab：上半部绘制一段干净的 DNA 双螺旋线描图，线条精确克制；下半部是横向 ACGT 碱基序列条，等宽字体，一处带选中框与变异标记。
中栏 Brain Forge：一张黑白为主、少量彩色强调的神经网络发育示意图，节点与边用细线精确绘制，不同细胞类型以三种高区分度的实色标注。
右栏 Danio Arena：俯视的竞技场平面图，白色背景，深色细线勾勒竞速场边界，内部是若干斑马鱼侧视简图、小的猎物符号、一个更大的捕食者轮廓与几个几何障碍块，形态像学术论文中的实验装置示意。
底部控制栏左端为 Pause 与 Reset 按钮，右端为灰色小字 Evolution / Experiment / Playback。

视觉风格：浅色学术版式。背景为暖白或极浅灰，用细规则线而非卡片阴影划分区域，网格感明确。主色为单一强调色，仅用于数值与激活态。字体为精确的无衬线体，数字用等宽字体。整体像一份严谨的科研论文插图或实验室白皮书页面，绝不追求商业感。

文字要求：所有界面标签为清晰可读的英文单词，字号统一，对齐严格。

负面要求：不要深色模式，不要渐变，不要阴影悬浮卡片，不要彩色插画感，不要圆润卡通造型，不要营销页元素，不要任何具体数值读数。
```

## 生成后自检清单

对照 `docs/验收清单.md` 的 Demo 部分与 `08 §12`：

- [ ] 三栏是否清晰可辨，且左中右内容对得上 DNA2Brain / Brain Forge / Danio Arena
- [ ] 顶部六项状态是否完整出现
- [ ] 底栏 Pause / Reset 是否在位
- [ ] 界面文字是否可读、无乱码
- [ ] 是否**没有**出现具体数值、曲线或统计图（红线）
- [ ] 主色用量是否克制（不超过画面 10%）
- [ ] 从三张变体中选定一张后，是否已把配色与间距值提取成 CSS 变量写进 `frontend/src/index.css`

## 选定后的下一步

参考图冻结后，按顺序做三件事：

1. 从选定图提取色板、字阶、间距刻度，替换/扩展 `frontend/src/index.css` 中的 HSL 变量；
2. 为 ECharts 补一套序列色板、为 Cytoscape 补网络图配色（当前 token 未覆盖，见 `08` 需求）；
3. 把风格词回填进 `artifacts/assets_placeholder/image_prompt_template.md` 里那三类素材（Fish sprite / Predator / DNA），使其与主界面同风格。
