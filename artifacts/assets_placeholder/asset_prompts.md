# 素材提示词（7 项补齐；与 `ui_reference_prompts.md` 同风格）

> 用途：补齐 `README.md` 清单里**只有名字、没有提示词**的那几项。
> 工具：ChatGPT 内置生图（GPT Image 2）。
> 风格基调：**16 位像素质感**（已由 `ui_reference_prompts.md` 的修订记录冻结）。
>
> ## ⚠️ 使用前必须替换两处占位
> 1. `{色板}` —— 从**选定的 UI 参考图**取色（≤32 色），写成具体 hex 列表。
>    **参考图未选定前不要批量生成本文件里的素材** —— 色板一变，全部作废。
> 2. `{画布色}` —— Arena 画布底色为 `#0B1220`，透明背景素材要确保在此底色上可辨。

## 通用规格（每条 prompt 都隐含这些，不必重复写）

| 项 | 值 |
|---|---|
| 质感 | 16 位像素，手工逐像素，边缘为清晰方形像素块，**无抗锯齿**，抖动点阵过渡 |
| 色板 | 受限调色板（整幅 ≤32 色），统一取 `{色板}` |
| 背景 | **透明**（PNG-24），Arena 内使用 |
| 输出 | 单张 sprite sheet：**均匀网格**排列，素材间留等距间隔，**无任何文字标注** |
| 尺寸 | 按 2× 出图（鱼 64×64 / 幼鱼 32×32 / prey 16×16 / 捕食者 96×96 / 瓦片 64×64），落库后按 1× 使用 |
| 负面 | 不要抗锯齿；不要平滑渐变；不要柔和阴影；不要玻璃拟态；不要写实三维；不要文字/水印；不要背景场景；**不要复制任何现有游戏的具体角色或道具**；**不要任何可读数值、曲线或统计图**（红线） |

## 1. logo（EvoGenesis 字标 + 图形标）

```text
生成 EvoGenesis 的品牌标识：一枚图形标 + 一行像素字标，透明背景，纯 16 位像素风，边缘为清晰方形像素块，无抗锯齿。图形标用一枚简化的斑马鱼轮廓与一段 DNA 双螺旋相互缠绕成环，两个母题各占一半，用 {色板} 中的高饱和色块拼成，不写实、不做体积光照。字标 "EvoGenesis" 用点阵像素字体横排，字母间距均匀、拼写清晰可读。整体气质是 16 位科学幻想实验台的商标，几何简洁、轮廓利落。提供两版：横排（图形标在左、字标在右）与正方形（只有图形标）。分辨率足够放大到 512 像素仍保持锐利像素边缘。负面：不要抗锯齿，不要渐变，不要柔化阴影，不要 3D 渲染，不要抄袭任何现有品牌或游戏标识，不要花边装饰。
```

## 2. 环境瓦片（水面 / 深水 / 草地 / 石块 / 沙地）

```text
生成一张像素环境瓦片素材表，透明背景（或纯色背景、瓦片本身可无缝拼接），16 位像素质感，无抗锯齿，受限调色板取 {色板}。包含五枚俯视瓦片：浅水面（蓝绿像素块配抖动点阵波纹）、深水面（更暗的同色系）、草地（草绿像素块配少量深浅颗粒）、石块（灰褐像素块、边缘有棱角高光）、沙地（暖黄像素块配细碎颗粒）。每枚瓦片为正圆角方形，左右与上下边缘必须能无缝拼接（同一枚与自身相邻时不出现接缝或突变），因此四边像素需自然延续。五枚共用一套明度关系，使它们能在地图上混铺而不打架。负面：不要抗锯齿，不要渐变，不要柔和阴影，不要写实材质，不要边缘描边，不要文字，不要复制任何现有游戏的地表素材。
```

## 3. 障碍 / 植物 / 岩石（Arena 内的实体道具）

```text
生成一张像素道具素材表，透明背景，16 位像素质感，无抗锯齿，受限调色板取 {色板}，俯视视角。包含下列道具各若干变体，网格排列、无文字标注：水草（三枚，不同高度与弯向，草绿配深绿描边）、芦苇（两枚，细长竖向）、石堆（三枚，灰褐方块堆叠，顶部有受光面、底部有暗面）、圆形鹅卵石（两枚）、沉木（两枚，木棕带纹理）。所有道具的重心与视觉重量要能衬托出「鱼是小而细长的」，即道具尺寸应明显大于鱼但低于捕食者。轮廓清晰，在深色水面 {画布色} 上仍可辨认。负面：不要抗锯齿，不要渐变，不要柔和阴影，不要写实材质，不要文字，不要背景，不要复制任何现有游戏的场景道具。
```

## 4. water background（Arena 全屏水底背景）

```text
生成一张无缝可平铺的水底背景，16 位像素质感，无抗锯齿，受限调色板取 {色板}，主色为深蓝绿（以 {画布色} 为基调向亮处扩展），俯视视角。用抖动点阵与稀疏的像素颗粒表现水体的深浅层次与细微杂质，整体**低对比、低信息量**，因为它要作为竞技场底层长时间铺满屏幕而不抢主体。四周边缘必须无缝平铺。不要出现任何具体生物、道具或文字。负面：不要抗锯齿，不要渐变，不要柔和阴影，不要高对比噪点，不要水波高光条带，不要生物或道具，不要文字，不要写实水纹。
```

## 5. cell-type icons（六类细胞类型）

```text
生成六个像素图标，透明背景，16 位像素质感，无抗锯齿，受限调色板取 {色板}，网格排列、无文字标注。每个图标用一个简洁几何符号代表一种细胞类型，六个之间必须在形状与颜色上都能一眼区分（不要靠颜色单独区分，形状也要不同）：例如圆形带核、方形带角、菱形、星形、环状、水滴形。每个图标用 1–2 像素深的描边勾勒轮廓，内部用一到两个色块填实。统一尺寸、统一线条粗细，适合在 16–24 像素下显示。不要画成写实的细胞切片或显微镜照片。负面：不要抗锯齿，不要渐变，不要柔和阴影，不要写实生物学绘图，不要文字或数字，不要背景。
```

## 6. neural glow（神经活动辉光）

```text
生成一张像素辉光素材，透明背景，16 位像素质感，无抗锯齿。包含三类可叠加的发光元素，网格排列、无文字：①神经元节点激活（一个亮核 + 一圈由抖动点阵构成的、亮度向外衰减的方块晕），提供三档强度各一枚；②连接边脉冲（一小段沿轴向的亮点串，用于表现信号沿边传播），提供两枚不同长度；③突触命中闪光（四向星芒形，短促、小而亮）。发光颜色取 {色板} 中的高亮色，晕的过渡必须用抖动点阵而非平滑渐变。这些元素会叠在深色脑网络图上，因此需要足够亮、但不得过曝成纯白一块。负面：不要抗锯齿，不要平滑径向渐变，不要柔和模糊，不要镜头光晕，不要文字，不要背景。
```

## 7. UI 状态特效（danger / hunger / mutation）

```text
生成一组像素 UI 状态特效，透明背景，16 位像素质感，无抗锯齿，色板取 {色板}，网格排列、无文字，共三组、每组三档强度：①危险（捕食者逼近）：从边缘向内收的红色警示斜纹/尖角，三档由疏到密；②饥饿（能量低）：暖黄到橙的脉动环，三档由细到粗；③变异（基因编辑后）：紫色（{色板} 的 violet）的螺旋碎片与碎裂像素点，三档由零星到密集。所有特效都必须能作为**边缘警示层**叠在面板边框上而不遮挡中央内容，因此元素集中在外框附近、中央保持通透。三组的主色必须互不混淆。负面：不要抗锯齿，不要渐变，不要柔和发光，不要文字或数字，不要整屏覆盖的实色块，不要抄任何现有游戏的 HUD。
```

## 8. PPT 封面视觉

```text
生成一张 16:9 的学术演示封面视觉图，16 位像素质感与精密图表的混合：左侧 2/3 是一幅俯视的像素水池竞技场（水面、草地与石块的像素瓦片，水中有细长像素斑马鱼、更小的猎物、一个更大的捕食者轮廓），右侧 1/3 是一段精确绘制的 DNA 双螺旋与一张神经元网络示意（节点与细线，干净矢量感），两者之间用一条渐变的分割带过渡。整体明亮、饱和、层次清楚，适合放大投影。画面上**不要出现任何具体数值、坐标轴、曲线或统计图**；不要出现标题文字（标题后期用真实字体叠上去）。负面：不要抗锯齿的伪像素，不要暗色压抑调，不要玻璃拟态，不要 3D 渲染写实材质，不要任何数值或图表，不要水印，不要复制任何现有游戏的角色或界面。
```

## 生成后自检（每一项都过一遍）

- [ ] 像素是否真的是**方形硬边**（不是被抗锯齿柔化的「伪像素」）
- [ ] 色板是否落在 `{色板}` 内（超出即与界面冲突）
- [ ] Arena 用素材是否**透明背景**，且在 `{画布色}` 上可辨
- [ ] 鱼是否在**极小尺寸**（16–48 px）下仍能辨认
- [ ] 瓦片类是否真的**可无缝拼接**
- [ ] 是否**没有**出现任何可读数值、曲线或统计图（**红线**）
- [ ] 是否**没有**与任何现有游戏资产雷同（**红线**）

## 与 3D DNA 新方案的衔接（2026-09-26 变更）

3D DNA 已改为 three.js 渲染（见 `frontend/README.md` 技术栈）。因此**不要**再生成「螺旋成品图」——
改为生成**可平铺的 DNA 纹理 / 碱基符号**，用于贴在程序化几何体上：

```text
生成一张可无缝平铺的 DNA 纹理，16 位像素质感，无抗锯齿，受限调色板取 {色板}。纹理内容为均质分布的碱基符号（A/C/G/T 各若干，用四种高区分度颜色）与细小的糖磷酸骨架连线，密度均匀、无中心焦点，使其在任何裁切位置都能自然延续。另外单独生成一排碱基符号条（A/C/G/T 横排，等距，点阵像素字体清晰可读），用于 2D 编辑条。负面：不要抗锯齿，不要渐变，不要柔和阴影，不要螺旋成品图，不要文字说明，不要背景场景。
```
