# 素材提示词（一图一素材 · 逐张生成）

> 用法：**一次生成一张**。每节就是一条可粘贴的提示词，产出**一个**素材（或一个紧密成套的小家族，
> 如同一条鱼的 4 帧摆尾——同图生成才能保证风格一致）。
> 工具：ChatGPT 内置生图。风格基调：**16 位像素质感**（`ui_reference_prompts.md` 已冻结）。
> 配套：`ui_reference_prompts.md`（3 张 UI 参考图）、`README.md`（清单与决策记录）。

---

## §0 每次生成前必须替换的占位

| 占位 | 填什么 |
|---|---|
| `{色板}` | 从**选定的 UI 参考图**取色（不超过 32 色），写成具体 hex 列表 |
| `{键控色}` | 抠图用的纯色背景，建议 `#FF00FF`（洋红）；**`{色板}` 必须不含该色**，否则抠图会挖掉素材本身 |
| `{画布色}` | Arena 画布底色 `#0B1220`，用于确认素材在深色上可辨 |

**色板未冻结前不要批量生成** —— 色板一变，全部作废。

## §1 通用规格（每条提示词都隐含，不必重复写）

| 项 | 值 |
|---|---|
| 质感 | 16 位像素，手工逐像素，边缘为**清晰方形像素块**，**无抗锯齿**，用抖动点阵表现过渡 |
| 色板 | 受限调色板（不超过 32 色），统一取 `{色板}`，**且不含 `{键控色}`** |
| 背景 | **纯 `{键控色}` 平涂**（见 §2 第 1 条：生图模型的"透明背景"不可信） |
| 出图 | 正方形 1024×1024；**素材居中、占画面约 60–70%**，四周留出纯键控色边距 |
| 负面 | 不要抗锯齿；不要平滑渐变；不要柔和阴影；不要玻璃拟态；不要写实三维渲染；不要文字/水印；不要场景背景；**不要复制任何现有游戏的具体角色/道具/界面**；**不要任何可读数值、曲线或统计图**（红线） |

## §2 三条现实约束（不先知道会白做）

**1. 生图模型的"透明背景"不可信。** 它通常输出**不含 alpha** 的图片；要"透明背景"时，
经常画成**假透明棋盘格图案**——那是画上去的花纹，不是真透明。所以本文件的提示词一律要求
**纯键控色背景**，由后处理（§6）把它抠掉。**先只生成 1 张验证抠图链路**，再批量做。

**2. 模型默认输出"伪像素"。** 它常给出**被抗锯齿柔化过的**像素风（边缘发虚、有渐变）。
后处理必须做 **最近邻（nearest-neighbor）缩小**——不能用双线性，否则等于再糊一次。
生成时给足尺寸（1024）也是为此：让模型画细节，缩小后边缘变硬。

**3. 尺寸与"各种大小的鱼"——不要按大小生成多套。**
Arena 里鱼的体型 `size` 是**连续变量**，绘图代码按它**实时缩放**
（`DanioArenaPanel.tsx` 的 `len = max(8, sr(f.size) * 10)`，`sr` 把世界单位映射到画布）。
因此**只需两套：成鱼 + 幼鱼**（幼鱼另行生成是因为小尺寸下需要更简化的形体，不是单纯缩小）。
成鱼在局内长大时由代码缩放即可；不要生成"小/中/大/特大"四套，那既没必要也不一致。

## §6 后处理与落地（生成之后）

**为什么必须后处理**：模型给的是 1024 大图 + 伪像素边缘 + 键控色底，**不能直接喂给 Canvas**。
建议流水线（**可按此写成脚本，我可以做**）：

1. **抠图**：按 `{键控色}` 去背景（洋红 `#FF00FF` 与调色板不重叠，因此可无损扣）。
2. **切分**：多枚/多帧的图按连通区域或等距网格切开，逐个裁到内容边框。
3. **最近邻缩小**：用 `nearest` 缩放到目标尺寸（**禁止双线性**，否则再度糊化）。
4. **调色板量化**：把颜色吸附到冻结的不超过 32 色，消除模型带进来的杂色。
5. **落位**：写入 `frontend/public/assets/`。
