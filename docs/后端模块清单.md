# 后端模块清单（`src/evogenesis/`）

> **管辖范围**：本文件拥有——后端（`src/evogenesis/`）的**文件级清单**：各包的文件构成、每个模块文件的职责一句话、职责语义的 owner 指向、以及 `scripts/` 薄壳与模块的映射。**不拥有**——层级与归属规则（`AGENTS.md`「项目目录结构／分层与归属」）、职责语义本身（各模块同目录 `.md`，本文件只引用摘要，冲突以模块文档为准）、参数取值（`configs/` + `docs/参数总表.json`）、字段名/类型（`schemas/`）、测试清单（`tests/TEST_PLAN.md`）。职责文字取自各模块 docstring 与同目录文档的「管辖范围」，本文件不另立定义。

> 快照：生成时点 `HEAD = 215507a`（`git rev-parse --short HEAD`）。包为 src-layout，导入前缀 `evogenesis.`；包根 `evogenesis/` 下 11 个任务包，`__init__` 之外 67 个模块文件（core 8 / genome 3 / development 4 / connectome 3 / arena 5 / evolution 5 / learning 5 / experiment 19 / pipeline 2 / viz 7 / api 6）。

## 0. 分层与依赖方向

`core/` 为唯一长期稳定机制层，被所有任务包依赖；任务包按数据流 `genome → development → connectome → arena → evolution` 单向引用；`learning` 横向接 `connectome`；`experiment`、`pipeline`、`viz`、`api` 为编排／对外／出图层，不反向被依赖（规则 owner：`AGENTS.md`「分层与归属」）。

## 1. core/ — 机制底座

职责语义 owner：`core/核心机制与数据流.md`（数据流总管；不定义模块内算法）。

| 文件 | 职责 |
|---|---|
| `config.py` | 配置加载与校验（core §0／§10#5） |
| `ids.py` | 稳定 ID 铸造（core §3.1） |
| `io.py` | 序列化读写（core §7） |
| `logging.py` | 运行日志，JSONL 字段对齐 OpenTelemetry Logs（core §0） |
| `registry.py` | 稳定 ID 注册表（core §0） |
| `seed.py` | 核心种子派生，多命名空间（core §3） |
| `tensors.py` | 跨框架转换 NumPy → torch（core §7） |
| `tracking.py` | 实验跟踪（core §0） |

## 2. genome/ — 遗传算子

职责语义 owner：`genome/生物学与进化遗传学基础.md`（二倍体、重组、mutation、dominance、epistasis、drift；产出表达后的基因组／gene products）。

| 文件 | 职责 |
|---|---|
| `config.py` | 基因组布局参数（取值 owner：`configs/default_model.yaml` `genome` 节） |
| `genome.py` | 二倍体基因组：结构、motif affinity、位点表达与遗传算子 |
| `motifs.py` | motif 目录：跨个体／跨代固定的 8×6 bp 目录（genome §6）；含 Mendel 装置（§3） |

## 3. development/ — GRN 与 RGCD 发育

职责语义 owner：`development/RGCD数学模型.md`（产出 `(A, Z, τ, W⁰, M)`、cell type、viability 判据）。

| 文件 | 职责 |

| `config.py` | RGCD 发育参数（取值 owner：`configs/default_model.yaml` `grn`／`rgcd` 节） |
| `grn.py` | 唯一正式离散 GRN（§4） |
| `development.py` | 发育阶段：domain 放置（§3）、分裂（§5）、cell identity（§6） |
| `rgcd.py` | 连接概率（§8）、初权（§10）、时间常数（§11）、viability（§7）与发育入口 |

## 4. connectome/ — DanioNet 结构与动力学

职责语义 owner：`connectome/DanioNet设计规范.md`（六类功能语义、12 维输入语义、神经动力学、连续动作、lifetime learning 与遗传边界、baselines／ablations；产出 activation／动作 `(ω, v)`／`ΔW`）。

| 文件 | 职责 |
