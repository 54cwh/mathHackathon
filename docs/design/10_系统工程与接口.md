# 系统工程与接口规范

## 1. 技术栈
### Backend / Model
- Python 3.12（uv 管理，`requires-python >=3.12`）
- PyTorch
- FastAPI
- NumPy
- Pydantic

### Frontend（待定，未冻结）
- 候选：Next.js、TypeScript、Canvas / Phaser.js、Cytoscape.js、WebSocket

要求 CPU 可运行，GPU 有则加速。

## 2. 仓库结构映射

项目采用单包 + 任务分层的仓库；设计包目录与之映射如下：

| 设计包目录 | 本项目 |
|---|---|
| `/frontend` | `frontend/` |
| `/backend` | `src/evogenesis/api/` + `scripts/` |
| `/model` | `src/evogenesis/genome/`、`development/`、`connectome/` |
| `/simulation` | `src/evogenesis/arena/` |
| `/experiments` | `configs/` + `scripts/` + `results/runs/` |
| `/assets` | `artifacts/`（+ `data/`） |
| `/checkpoints` | 冻结→`artifacts/`；实验→`results/runs/<id>/` |
| `/demo` | `frontend/` + `scripts/start_demo.*` |
| `/config` | `configs/` |
| `/docs` `/prompts` `/schemas` | 同名保留 |

目录职责与 `AGENTS.md` 的「项目目录结构」一致。

## 3. 稳定 ID
- fish_id
- genome_id
- generation_id
- experiment_id
- environment_id

前端不得使用数组下标当 identity。

## 4. API
### POST /genome/mutate
输入 genome + chromosome + homolog + position + new_base。

### POST /develop
输入 genome + seed；返回 developmental trace + phenotype。

### POST /breed
输入 parent A/B + seed；返回 offspring + meiosis trace。

### POST /arena/evaluate
输入 phenotypes + environment + seed；返回 behavior metrics。

### POST /evolution/run
输入 population + generations + environment + seed。

### GET /fish/{id}
Fish Card。

## 5. WebSocket
实时传：
- fish transforms
- selected-fish neural activation
- energy
- events
- generation progress

不每帧发送全部 48×48 matrix。

## 6. Seed Manager
统一设置：
- Python random
- NumPy
- PyTorch CPU
- PyTorch CUDA

mutation / crossover / development / Arena spawn 全部由 master seed 派生。

## 7. Offline
现场不得依赖：
- OpenAI API
- external model API
- remote DB
- remote asset CDN

## 8. Docker
提供 Docker 用于复现；现场优先直接本机运行。

## 9. One-click Demo
目标：
```powershell
.\scripts\start_demo.ps1
```

或：
```bash
./scripts/start_demo.sh
```

## 10. Git
开发期 private；提交时按比赛要求 public。schema/config 变更必须双方同步。
