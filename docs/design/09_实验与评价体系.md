# 实验设计与评价体系

## 1. Reproducibility
Demo seed 与 research seeds 分离。

正式结果至少：

\[
n=3
\]

random seeds，报告 mean ± std。

## 2. Experiment A — Genome → Architecture
采样 genomes，记录：
- motif affinity
- GRN final states
- neuron count
- cell-type distribution
- edge density
- tau distribution

## 3. Experiment B — Single-base Mutation
对代表性 haplotype 的 256 positions 逐位做 deterministic alternative-base mutation。

计算：

\[
\Delta Expression,\quad d_{edge},\quad d_\tau,\quad \Delta Behavior
\]

生成 Genome Sensitivity Map。

## 4. Experiment C — Baseline
- MLP
- GRU
- Fixed Sparse RNN
- DanioNet

控制：
- 相同数据
- 相同训练预算
- 参数量同一数量级
- 相同 evaluation episodes

指标：
- survival
- prey capture
- escape success
- energy efficiency
- inference latency
- parameter count
- active edges

## 5. Experiment D — Ablation
- Full DanioNet
- w/o GRN
- homogeneous tau
- w/o spatial wiring cost
- P1：w/o epistasis

## 6. Experiment E — Robustness
随机删除 active edges：
- 5%
- 10%
- 20%

比较 behavior / fitness degradation。

## 7. Experiment F — Environmental Selection
相同 initial population 分别进入：
- Food Rich
- Predator Rich
- Resource Scarce

运行 10–20 generations，记录：
- allele frequency
- phenotype frequency
- viability
- fitness
- neuron count
- edge count
- tau statistics

## 8. Mendelian validation
大量 offspring 验证 AaBb × AaBb。显示 empirical ratio，并计算：

\[
\chi^2=\sum_i\frac{(O_i-E_i)^2}{E_i}
\]

统计波动属于模型正常结果。

## 9. Efficiency
\[
Efficiency=
\frac{TaskPerformance}
{ActiveConnections\times Timesteps}
\]

同时单独报告：
- parameter count
- active edges
- latency
- peak memory（可测时）

## 10. 正式结果原则
- 不人工挑选最好一次作为结论。
- Demo 可使用稳定 seed。
- 正式结果必须来自固定 protocol。
- 所有图可回溯到 run directory。
