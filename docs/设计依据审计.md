# 设计依据审计

> 状态：v1.0（2026-09-26）
> 目的：逐份核对 `src/evogenesis/` 各模块设计文档中的**设计决策**是否有可核实的外部依据，区分「缺引」「需改口径」「本质人工装置」三类，给出处置与检索需求。
> 上位：`AGENTS.md`（证据显式接线、不确定性诚实）；文献事实来源：`research/notes/bibliography.md`（`[bib#n]`）。
> 范围：设计**依据**；各文档末尾「阅读问题」中的**实现完整性缺口**（参数初始化 G1、动作合成 G3 等）不在此列，归实现 lane。

| 标记 | 含义 | 处置 |

## 表 2 · ⚠️ 需限定或改值

| 设计项 | 位置 | 问题 | 处置 |
|---|---|---|---|
| `μ = 0.001` / base / gamete | genome §5；evolution §8；总纲 §6 | 比真实突变率（~10⁻⁸/base/代）高约 10⁵ 倍 | 引数字演化惯例（Avida）并标注为**计算速率**；或改值（检索 R1） |
| 选择强度 `β = 3`（softmax） | genome §8；evolution §5 | 适应度分量归一化方式未定，β 无确定含义 | 改为排名/锦标赛选择，或先冻结归一化（检索 R2） |
| `fitness_weights = 0.35/0.25/0.20/0.20` | evolution §6；总纲 §6 | 拍定值，且依赖未定的归一化 | 显式标注为人为权重 + 做敏感度分析 |
| `τ_i ∈ [1,10]` | RGCD §11；总纲 §6 | 归一化单位，无外部范围依据 | 引膜时间常数 10–100 ms 作量级参照，说明无量纲化（检索 R7） |
| `crossover = 0.5` / 每对一次 | genome §4；evolution §2 | 单点/两点交叉常见 0.6–0.9；0.5 对应均匀交叉 | 改口径或改值（检索 R2） |
| motif affinity `1 − d_H/|M|` + TopKMean | RGCD §2 | 无对照/无出处 | 引 PWM/PSSM 说明采用简化式的理由（检索 R5） |
| `sensing_radius = 18` | arena §4 | 单位按 BL 时远大于幼虫观测值 | 按体长（BL）改口径（configs 待与李辰钊确认） |

| 能量式 `E − (C_base + C_move·v²) + R_food` | arena §6 | 缺引用 | 引游泳代谢/能量学（检索 R7） |
| growth / biomass | arena §7 | 缺引用 | 引生长与代谢（检索 R7） |
| BC 损失与 `K = 20` | DanioNet §6；learning §3 | BC 为标准方法，但 K=20 无依据 | 引 BC/imitation 综述；K 标注为预算选择（检索 R6） |
| baseline 对照、"参数量同数量级" | DanioNet §8；experiment §4 | "同数量级"未量化 | 引 NEAT/HyperNEAT；给出容许倍数（检索 R6） |
