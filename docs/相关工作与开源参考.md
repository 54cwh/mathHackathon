## 1. 已有研究边界

EvoGenesis 不宣称"第一次用 genome 生成网络"。以下方向已被覆盖：

- **genomic bottleneck / 先天结构**：Zador 2019 `[bib#1]`；Shuvaev 等 2024 `[bib#3]`（weight matrix 的有损压缩）。
- **developmental encoding**：Barabási 等 2023 `[bib#2]`（以 wiring rules 生成权重，而非直接更新权重）。
- **发育规则生成 connectome**：Richter & Schneidman 2025 `[bib#4]`（cell type / birth time / distance / pruning）。
- **neuroevolution**：Miikkulainen 2025 `[bib#5]`；NEAT / HyperNEAT 基线见 `research/reference/design-basis-connectome.md`。
- **紧凑基因组控制拓扑**：Sudarshan 2026 `[bib#15][bib#16]`（Neural DNA，`preprint`，**学习得到的** <300 参数基因组，type-based compatibility rules）。

因此立论定位是"统一链路 + 可编辑可遗传的显式发育解码"，而非发明"genome→network"本身。

## 2. EvoGenesis 的集中创新

- editable diploid ACGT genome
- explicit DNA → motif → discrete GRN → cell identity → connectome
- genome 同时生成 topology 与 neuron dynamics
- Mendelian inheritance / recombination / mutation 与 developmental decoder 统一
- single-base → expression → connectome → behavior causal analysis
- interactive ecological selection
- zebrafish-inspired sensorimotor prior

其中"genome 同时决定 topology 与 dynamics（特别是异质 τ）"是与 `[bib#2][bib#4]` 的主要差异点。

## 3. 生物学依据

- **prey capture / 视觉追踪**：Trivedi & Bollmann 2013 `[bib#8]`
- **heading direction / 左右竞争**：Petrucco 等 2023 `[bib#6]`；Dunn 等 2016 `[bib#7]`
- **hunger 调制 approach–avoidance**：Filosa 等 2016 `[bib#9]`；Zaupa 等 2024 `[bib#10]`
- **历史依赖决策 / integrator-memory**：Zhao 等 2026 `[bib#11]`
- **真实调控基因组（对照，不导入）**：DANIO-CODE，Baranasić 等 2022 `[bib#12]`
- **连接组组织**：Dorkenwald 等 2024 `[bib#14]`；ZBrain Atlas（Randlett 等 2015，见 `core/核心机制与数据流.md` §8）

这些用于设计 prior，不等于逐细胞真实复刻；标注为"人工设计选择"的项见 `docs/设计依据审计.md` 表 3。
