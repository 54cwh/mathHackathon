# 系统工程与接口规范

## 1. 技术栈
### Backend / Model
- Python 3.11+
- PyTorch
- FastAPI
- NumPy
- Pydantic

### Frontend
- Next.js
- TypeScript
- Canvas / Phaser.js
- Cytoscape.js
- WebSocket

要求 CPU 可运行，GPU 有则加速。

## 3. 稳定 ID
- fish_id
- genome_id
- generation_id
- experiment_id
- environment_id

前端不得使用数组下标当 identity。

## 4. API
### POST /genome/mutate
输入 genome + chromosome + homolog + position + new_base。

### POST /develop
输入 genome + seed；返回 developmental trace + phenotype。

### POST /breed
输入 parent A/B + seed；返回 offspring + meiosis trace。

### POST /arena/evaluate
输入 phenotypes + environment + seed；返回 behavior metrics。

### POST /evolution/run
输入 population + generations + environment + seed。

### GET /fish/{id}
Fish Card。

## 5. WebSocket
实时传：
- fish transforms
- selected-fish neural activation
- energy
- events
- generation progress

不每帧发送全部 48×48 matrix。

## 6. Seed Manager
统一设置：
- Python random
- NumPy
- PyTorch CPU
- PyTorch CUDA

mutation / crossover / development / Arena spawn 全部由 master seed 派生。

## 7. Offline
现场不得依赖：
- OpenAI API
- external model API
- remote DB
- remote asset CDN

## 8. Docker
提供 Docker 用于复现；现场优先直接本机运行。

## 9. One-click Demo
