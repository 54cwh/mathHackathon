# AI 工作流

## 1. 总流程
```text
Research
→ Modeling
→ Coding
→ Testing
→ Visualization
→ Report
→ Human Review
```

## 2. Research
输出：
- bibliography
- claim–source map
- related work comparison
- biological evidence

人工审核：
- 来源
- 时间
- 物种
- evidence strength

## 3. Modeling
输出：
- variables
- equations
- dimensions
- assumptions
- boundary conditions
- experiment plan

原则：不得写一套“高级数学”而代码实现另一套。

## 4. Coding
输入冻结 equations/schema，输出 modules/tests/config hooks。所有随机过程接 seed manager。

## 5. Testing
重点：
- Mendel
- mutation
- crossover
- GRN range
- viability
- Dale sign
- reproducibility
- NaN/Inf

## 6. Visualization
装饰视觉可由生成式 AI 生成；所有数据图与模型状态必须来自真实程序。

## 7. Report
只从冻结模型与真实 experiment outputs 写作，不把 Future Work 写成结果。

## 8. Human Review
最终模型、代码、实验、引用和陈述由团队成员审核。

## 9. Prompt 归档
所有关键 prompt 存 `/prompts`，保留任务、输入、输出格式和验收条件。

## 10. AI 使用声明
单独放入 `prompts/AI_USE_DECLARATION.md`，报告中按比赛要求引用。
