# 相关工作与开源参考

## 1. 已有研究边界
已有方向已经覆盖：
- genomic bottleneck
- developmental encoding
- cell-type / distance based connectome generation
- neuroevolution
- compact genome controlling topology
- Neural DNA

因此项目不宣称“第一次用 genome 生成网络”。

## 2. EvoGenesis 的集中创新
- editable diploid ACGT genome
- explicit DNA → motif → discrete GRN → cell identity → connectome
- genome 同时生成 topology 和 neuron dynamics
- Mendelian inheritance / recombination / mutation 与 developmental decoder 统一
- single-base → expression → connectome → behavior causal analysis
- interactive ecological selection
- zebrafish-inspired sensorimotor prior

## 3. 生物学依据
重点参考：
- zebrafish visual prey capture
- ARTR-related turning / mutual inhibition
- heading-direction ring attractor
- hunger-modulated approach / avoidance
- thalamus–brainstem attractor/integrator
- DANIO-CODE regulatory genomics

这些用于设计 prior，不等于逐细胞真实复制。
