## 3. 核心问答

### 你们设计了什么？
RGCD：DNA 先形成调控状态，再决定 cell identity、连接概率和 neuron-specific time constant，使 topology 和 dynamics 由 genome 经发育生成。

### DNA 是装饰吗？
不是。base edit 影响 motif affinity、GRN、cell composition、connectome、tau，最后影响行为；中间状态均可查看。

### 为什么斑马鱼？
它提供清晰的视觉捕食、威胁回避、左右运动竞争、时间积分和内部状态调制计算问题。

### 9:3:3:1 是创新吗？
不是。它是连接 Mendelian segregation 与 neural phenotype segregation 的经典测试场景。

### 有人做过 genome 生成神经网络吗？
有 developmental encoding、genomic bottleneck 和 Neural DNA 等相关工作。本项目重点是可编辑二倍体 DNA、显式调控—发育链、异质 dynamics、Mendelian inheritance、single-base causal analysis 和 ecological selection 的统一交互系统。

### 为什么后天权重不遗传？
用于明确分离 evolution 和 lifetime learning：后代继承 developmental program，而不是父代训练结果。
