# 交互与可视化设计

## 1. 主界面
系统直接进入实验台：

```text
┌───────────────────────────────────────────────────────┐
│ EvoGenesis | Env | Generation | Population | Seed      │
├────────────────┬────────────────┬─────────────────────┤
│ DNA2Brain Lab  │ Brain Forge    │ Danio Arena         │
│                │                │                     │
├────────────────┴────────────────┴─────────────────────┤
│ Evolution / Experiment / Playback Controls           │
└───────────────────────────────────────────────────────┘
```

最终视觉主题等待参考图后冻结，功能结构先实现。

## 2. DNA2Brain Lab

### 3D DNA
承担视觉冲击，不承担精确编辑。

### 2D nucleotide strip
承担真实编辑：

```text
... A C G T A C G ...
          ↑
```

显示：
- chromosome pair
- maternal / paternal haplotype
- locus
- motif
- mutation marker
- allele label

## 3. Mutation 两种模式

### Free Edit
任意修改一个 base。

### Story Mutation
预先验证的：
- Neutral SNP
- Memory-sensitive SNP
- Threat-sensitive SNP

Story Mutation 只预选“经过真实模型能产生清晰变化”的位置，不写死下游行为。

## 4. Brain Forge
动画顺序：

```text
DNA motif
→ q(S)
→ GRN state over 12 development steps
→ precursor division
→ cell differentiation
→ connections appear
→ DanioNet activates
```

所有中间图来自真实模型状态。

## 5. Before / After
SNP 修改后并排显示：
- DNA difference
- motif affinity
- GRN expression
- cell composition
- edge additions/removals
- tau distribution
- Arena behavior metrics

## 6. Fish Card
点击鱼后显示：
- ID
- generation
- genotype
- abbreviated DNA
- cell composition
- active neurons
- active edges
- fitness
- survival
- captures
- escapes
- energy
- size

操作：
- Parent A
- Parent B
- Compare
- Export Genome

## 7. Neural Activity
Arena 可 pause / slow-motion。选中鱼后 Brain Forge 实时显示：
- activation
- sensory pathway
- prey/threat activity
- integrator activity
- left/right motor competition

## 8. Evolution Dashboard
必须有：
- generation
- p(A), p(B)
- genotype / phenotype frequency
- fitness distribution
- viability rate
- mean neuron count
- mean edge count
- mean tau
- environment-change marker

## 9. 排行榜
- highest fitness
- longest survival
- most prey
- best energy efficiency
- unusual genome / largest connectome change

## 10. Manual Control
P2。用户可临时操控一条鱼；Manual Control 不进入正式实验数据。

## 11. Virtual CRISPR
P1。调用同一个 nucleotide edit API：
target → edit → apply → re-develop → compare。

统一名称：**Virtual CRISPR / in-silico genome editing**。

## 12. 生成式视觉素材边界
允许用于：
- background
- sprites
- logo
- icons
- molecular texture
- PPT visuals

禁止用于伪造：
- experiment curves
- network graphs
- metrics
- sensitivity maps
- statistical results
