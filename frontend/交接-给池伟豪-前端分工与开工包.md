## 4. 色板与字体：只有一个写法是对的

**品牌 24 色已冻结为 v0.1**（不等生图，理由见 `交互与可视化.md` §14 的 Q3）。
唯一定义处：`frontend/src/design/palette.ts`。Tailwind 里走 **`brand` 命名空间**：

```
bg-brand-ink   text-brand-foam   border-brand-stone-shadow   text-brand-danger-red
```

> ⚠️ **陷阱（会静默不生效）**：写 `bg-ink` / `text-foam` 是**错的**。
> Tailwind 的 `colors.brand = {...}` 把 `brand` 当**命名空间**，所以类名必须带 `brand-`。
> 写错时**不报错、也不出颜色**，只是什么样式都没有 —— 本轮我本人就在这里误判过一次。

**字体口径**（自托管于 `public/fonts/`，现场离线）：

| 用途 | 类名 / 字体 | 规矩 |
|---|---|---|
| 正文 | 默认（Inter） | — |
| 数值 / 代码 | `font-mono`（JetBrains Mono） | 所有数字读数 |
| **英文标签 / 标题** | `font-pixel`（Press Start 2P） | **只给英文**；它已关抗锯齿 |
| **中文叙述** | 默认字体 | **不要**套 `font-pixel`（像素字体不覆盖 CJK） |

**几何**（硬规则）：**无圆角**（`rounded*` 一律不用，`R2-4`）、**无阴影**、
分割线用 1px `border border-border`。

### 10.3 ⚠️ 你的 lint 有一处**假阳性**，我修了（请知悉）

### 10.4 本轮新查明的一类缺陷：**注释 / 键名会被 Tailwind 当类名**（最重要）

Tailwind 扫的是**原始文本**（不剥注释）。任何与工具类同名的**小写单词**都会被切出候选，并生成
「没人用」的死 CSS。本轮实测命中**三类来源**：

| 来源 | 例子 | 产出的死 CSS |
|---|---|---|
| TS **属性访问** | `DNA.shadow` | `.shadow` + `--tw-shadow*`（连带整套 `--tw-ring-*`） |
| TS **对象键** | `tokens.ts` 的 shell token 键 `ring:` | `.ring` |
| **英文注释** | `geometry.ts` 的 `rounded to…`；`palette.ts` 注释里的 `` `rounded-lg` `` | `.rounded` / `.rounded-lg` |

静态检查抓不到前两类（它剥注释，也不把属性访问当类名），**所以真正的兜底只能是 `blocklist`**：

```ts
// tailwind.config.ts
blocklist: ["ring", "shadow", "rounded", "blur", "transition", "animate", /* + 常见刻度 */]
```

效果：产物 CSS **10.21 → 9.50 kB**，且这类泄漏**结构上不可能再发生**。

> **给后来人的规矩**：起键名 / 写注释时**别用** shadow、blur、rounded、ring、transition、animate 这几个词。
> （`tokens.ts` 的 `ring:` 键我**没动** —— 改名会动 `--ring` 这个 shadcn 外壳契约的变量，属你的 lane。）
