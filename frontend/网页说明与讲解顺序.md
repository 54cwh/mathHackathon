# 网页说明与推荐讲解顺序

> **管辖范围**：本文件只做两件事——(1) 用最短篇幅说明这个网页**是什么、由哪些块组成**；(2) 给出**推荐的讲解顺序**。
> 它**不拥有**任何契约、字段、数值与算法（那些归 `交互与可视化.md` 与此目录各模块文档），也**不替代**逐句台词
> （那是 `演示讲稿.md`）。三者冲突时，契约以 `交互与可视化.md` 为准，台词以 `演示讲稿.md` 为准。

## 1. 这个网页是什么

一句话：**一条「基因 → 发育 → 脑 → 行为 → 演化」链路的实时窗口**——屏幕上每个画面都来自链路的真实中间状态，
不是示意动画，也不是把现成模型套一层界面。

它把同一套代码的三种用法放在一个页面里：

| 用法 | 位置 | 用途 |
|---|---|---|
| **实验台**（默认） | 底栏 `Experiment · 实验台` | 看 4 条鱼在生态里活动、点个体回看它的基因与脑、逐代演化 |
| **演化视图** | 底栏 `Evolution · 演化` | 只看**磁盘上的正式实验产物**（逐代曲线），不放现场动画 |
| **手动操控** | 底栏 `Playback · 手动操控` | 给评委亲手操控一条鱼，**不进正式数据** |

## 2. 界面骨架（从上到下）

| 块 | 内容 | 作用 |
|---|---|---|
| **顶栏** | 后端健康点；`Env / Generation / Fish / Prey / Step / Seed` | 全场状态的单一读数条（Step 涨=仿真在推进） |
| **导演线** | `SEED → GENOME → DEVELOP → ARENA → EVOLVE` + 单一 `Next` + `AUTO DEMO` | 把"下一步该做什么"固定成一条线；门控未过会**停在该段**，不跳步 |
| **主视图** | 三档视图（见上表） | 每档一个完整工作区 |
| **底栏** | `Pause / Release`、`Reset`、视图切换 | 暂停看细节、整会话重置、切视图 |

主视图内部（实验台）三栏：左栏 **DNA2Brain Lab**（`GENOME` 基因组编辑 + `PHENOTYPE` 表型），
中栏 **Brain Forge**（`DEVELOPMENT PIPELINE 发育管线` + `CONNECTOME LAYER` + `ACTIVATION 神经活动`），
右栏 **Danio Arena**（竞技场画布 + `FISH CARD` + `LEADERBOARD` + `EVOLVE` + `SPEED`）——
点右栏画布上的鱼，左栏会载入它的 DNA、中栏会显示它的脑与读数。

## 3. 推荐讲解顺序

原则：**先讲"为什么"，再讲"改了什么"，最后讲"结果"**——顺序与赛题四问（为什么改 → 改了什么 → 结果如何 → 有什么价值）一致。
每一步都落到一句可记住的结论；时间按 9 分钟配，压到 5 分钟时按括号内取舍。

| # | 时长 | 在哪 | 怎么动 | 讲完要留下的结论 |
|---|---|---|---|---|
| 0 | 20 s | 不在页面 | 不用鼠标 | 自然系统的网络由基因经发育生成，主流网络是人手指定的架构 |
| 1 | 40 s | `GENOME`（`DNA2Brain Lab`） | 指四条单倍体条带 → 改**一个**碱基 → `MUTATE` → `DEVELOP` | 基因是**可精确编辑、可复现**的输入，改一个碱基表型就变 |
| 2 | 90 s | `DEVELOP`（`Brain Forge`） | 指阶段轨一路走；拖时间线看 GRN 点亮、子代标绿、`P` 与 `A` 交替；指面板下方五类 `ACTIVATION` | 中间每一步**可指认、可复算**；不表演模型里不存在的动画 |
| 3 | 90 s | `ARENA`（`Danio Arena`） | 点一条**基因鱼** → 左看 DNA、中看脑；再看场上捕食与排行榜 | 场上是两种鱼：**规则鱼（原模型的替代：手写控制器）** vs **基因鱼（改后模型：自己基因发育出的网络）** |
| 4 | 60 s | `ARENA` 的 `EVOLVE` 区 | **不用点**：等本轮结束（跑满，或全鱼阵亡）——自动进下一代 | 演化**一代一幕、可打断**：评估 → 折算适应度 → 选择繁殖 → 重建种群 |
| 5 | 60 s | `Evolution · 演化` | 左栏现场 `LAUNCH` 一个小实验 → 在 `DISK RUNS` 点它看逐代曲线 | 出示的是**磁盘上的真实产物**，重启还在、可复跑 |
| 6 | 40 s | `Playback · 手动操控`（可选） | 方向键操控一条鱼，其余鱼仍由各自网络驱动 | 这是给评委的**体验**，不是研究证据 |
| 7 | 20 s | 收尾 | — | 贡献是"可控输入 + 可指认的发育 + 每个个体自己的脑 + 逐代可验证"，界面只是把链路指给你看 |

**撑场时的两个安全动作**：① 随时按 `Pause` 停下来细看（`Release` 恢复；**暂停期间不会自动换代**）；
② 一轮结束会自动进下一代，想重看本回合就点 `RESTART · 重开一轮`（保留当前种群与 generation；`Reset` 才是整会话重置）。

## 4. 口径提醒（引用数字前必说）

- 口语里的"捕获率"在本项目有**三个不同口径**（绝对速率 / 个体接触转化率 / 汇总比值），实测可差 7 倍；
  引用任何一个都**必须说明是哪一个**。
- 捕食的分母（遭遇数）**严重右偏**：少数个体长期蹲守会把均值拉高，**不能只报一个均值**。
- `energy_efficiency` 是**每步速率**（约 10⁻³ 量级、非正），**不可**与 0–1 的比值同轴比较。
- **不要替论文说话**：学习前后对照与基线对照在论文中仍是**待补**，本页面展示的是**机制链路与现场观测**；
  `FLOPs`、推理速度、能耗**尚未测量**，被问到就直说未测。

## 5. 常见追问（一行作答）

- **"和 HyperNEAT 的区别？"** → 可搜索的对象上移一层：搜的是**基因组**，网络结构是发育算子的**产物**；且适应度来自闭环生态，不是静态基准。
- **"DNA 是装饰吗？"** → 改一个碱基会影响 motif→GRN→细胞组成→连接组→τ，最后影响行为，中间状态都能在页面上点到。
- **"后天学的会遗传吗？"** → 不会，且这是设计：结构冻结、只扰动当代权重，$\Delta W$ 不进繁殖通路。
- **"为什么是斑马鱼？"** → 它提供视觉捕食、威胁回避、左右运动竞争、时间积分这几个清楚的计算问题。
