## 1. 启动与自检

### 1.1 两种起法

| 场景 | 命令 | 打开 |
|---|---|---|
| 现场演示（推荐） | `make demo` | 构建 `frontend/dist` + 起后端，自动开 `http://127.0.0.1:8000` |
| 开发热更 | 终端 A：`uv run python scripts/serve_api.py --port 8000`；终端 B：`npm --prefix frontend run dev` | `http://127.0.0.1:5173/`（vite 把 `/v1` 代理到 `:8000`，WS 同） |

- `make demo` 走 `scripts/start_demo.sh`：`dist/` 不存在才构建；端口用 `EVOGENESIS_PORT` 覆盖（默认 8000）；`Ctrl-C` 会连带关掉后端。
- **现场完全离线**：字体、图标、DNA 素材全部本地打包，不请求外网。

### 1.2 起服后 30 秒自检（四条）

1. 顶栏左侧**健康点**：绿 = `ok`，红 = 后端不可达，灰 = 还没探到（10 s 一次，`GET /v1/health`）。
2. 顶栏 `Seed` 应为 **250927**（前端唯一硬编码种子，见 §7 红线）。
3. 右栏 Arena 有鱼在游、左下角 `step` 在涨（默认步速 20× ⇒ 约 200 步/s）。
4. 底栏视图标签可点，切换不白屏（三个视图**常驻挂载**，切换不重建状态）。

### 1.3 改了后端代码一定要重启 API

`uvicorn` 只在启动时加载代码；**旧进程会静默忽略新加的查询参数**（FastAPI 不报错），表现为"前端参数发出去了、后端毫无反应"。已在 `Playback` 视图加了显式防线：`/v1/health` 的能力位 `manual_control` 为假时显示红色告警。

## 3. 视图一：Experiment 实验台（三栏，默认视图）

三栏从左到右：**DNA2Brain Lab**（基因与表型）| **Brain Forge**（脑与发育）| **Danio Arena**（生态与演化）。
三栏**常驻挂载、用显隐切换**——这样切视图不会重建会话、不会重抽基因组、不会丢任务列表。

### 3.1 DNA2Brain Lab（左栏）· 面板标题 `DNA2Brain Lab · 基因 → 大脑`

**`HELIX (SCHEMATIC)` 区**：像素风双螺旋，**示意素材**（纵向无缝平铺滚动）。它**不承载碱基身份**，右下角标注"示意素材 · 非互补配对"。真实碱基与选中位点看下面四条条带。

**四条单倍体条带**（`P0 MAT / P0 PAT / P1 MAT / P1 PAT`，共 **512** 个位点，线性顺序即 `position ∈ [0, 512)`）：
- 点任意碱基格 → 选中该位点（编辑器 `POS` 同步），窗口以选中位点为中心开窗（每链 20 格）。
- 条带下方写明：**同源位点之间不是碱基配对**（两条同源链各自独立随机，不存在 A–T / C–G 互补）——不要按"双螺旋配对"解读。

**编辑器 `GENOME` 区**：

| 控件 | 做什么 | 注意 |
|---|---|---|
| `GENOME` 右侧 id | 当前基因组稳定 ID（超长截断显示） | 截断只影响显示，不影响身份 |
| `POS` | 位点编号 0–511，可直接输入 | 越界会被夹到区间内 |
| `BASE` | 突变目标碱基 `A / C / G / T` | — |
| `MUTATE · 突变` | 在 `POS` 处把碱基改成 `BASE`，产出一个**新基因组**；下方显示 `pos N: X → Y · new g…` | 序列已变 ⇒ 旧表型作废（自动清空） |
| `DEVELOP · 发育` | 用**当前序列**跑一次 RGCD 发育 | 结果写入右下的 `PHENOTYPE`，同时把轨迹推给中栏 `Brain Forge`，并把该个体送进右栏 Arena |
| `NEW · 新基因组` | 抽一个新的参考基因组，清空突变与表型 | 参考种子来自 `configs/demo_seed.yaml` |

- **面板提示的用法**：先点 `DEVELOP` 取基线，再 `MUTATE` 后点 `DEVELOP`，对比表型差异。
- 发育种子固定 `seed 0`（可复现；面板 `PHENOTYPE` 行右侧显示 `seed 0 · viable / non-viable`）。
- **与右栏联动**：点 Arena 画布上的**基因鱼** → 本面板自动载入它的基因组并立即发育（三栏联动）；`DEVELOP` 出的个体会自动入列会话，会话还没建好时先排队、就绪后补送。

**`PHENOTYPE · 表型` 区**（真实数值，不是示意）：

| 读数 | 含义 |
|---|---|
| `neurons` | 发育落定的神经元数 $N$ |
| `edges` | 落定的突触边数 |
| `density` | 边密度（保留 3 位小数） |
| `tau` | 时间常数均值 $\bar\tau$（保留 3 位小数） |
| 行右 `viable / non-viable` | 是否通过可育性判据 |

### 3.2 Brain Forge（中栏）· 面板标题 `Brain Forge`

**上半：脑画面**——按发育轨迹的**真实几何**绘制（逐神经元坐标、细胞类型、真实邻接边、表达强度）。注意：连接层**只在"连接组成形"阶段**出现（否则它与"细胞分化"画面相同）。

**`CONNECTOME LAYER · 连接组图层` 行**：

| 控件 | 作用 |
|---|---|
| `edges N` | 当前样本的真实边数 |
| `ON / OFF` | 连接层显示开关（无 `edges` 样本时禁用） |
| `P / A` | 连接组两幕真值：`P` = 模型概率场 $\sigma(\ell)$；`A` = 一次采样得到的邻接。位于 `connectome` 阶段时每 1.2 s **自动交替** |

**`DEVELOPMENT PIPELINE · 发育管线` 块**（时间线 + 曲线，数据来自 DNA 面板的 `DEVELOP`）：

- 阶段轨（7 项，固定顺序）：`MOTIF → q(S) → GRN → DIVISION → DIFFERENTIATION → CONNECTIONS → DANIONET`。
  - 当前项高亮；走过的高亮为普通底色；未到的置灰。
  - 末项 `DANIONET` 是**实时激活指示**（绿色 = 该个体正在推送神经活动），与 `CONNECTIONS` 并列、不取代它。
  - 阶段判定口径：`grn` 轨迹的 `step 0` 归 `q(S)`，`step ≥ 1` 归 `GRN` 迭代。
- `PLAY / PAUSE` + 游标 `n/N` + 当前阶段名；拖动**时间线滑杆**即暂停并定格到该帧。
- 曲线与读数：`神经元数`（折线）、`motif 亲和度 q(S)`（8 维条形，**仅 `q(S)` 阶段显示**）、`平均表达 |g|`（折线）、底部 `分裂数 · 连接数` 与 `max|g|`。
- 没有轨迹时（还没发育）显示"尚无发育轨迹。在左侧 DNA2Brain Lab 点 DEVELOP 开始。"

**下半：`ACTIVATION · 神经活动` 区**（实时）：

- 数据来自**当前会话中该个体自己的 DanioNet**，随 Arena 推进更新（面板只订阅 `brain.activation`，节流 200 ms；**不驱动**会话）。
- 行右 `step N · fish M`；`neurons / mean / peak` + 直方图（最多 64 根，按步长抽稀，不改变数值含义）。
- **五类语义读数**（按该鱼自己的发育产物 `cell_type` + 坐标复算）：`sensory / prey / threat / integrator_memory` 四项均值，加 `motor L−R (ω)` 与 `motor L·R`。
  - 左右 motor 池按发育坐标 $x$ 的中位数二分；$\omega=\tanh(L-R)$。
  - **缺域记"未定义"（不补 0）**。
  - 只有"显示的鱼 == 当前个体"时才出这组读数；否则只出面元读数并标注"（任取一条）"。
- 会话为空 / 非模型驱动时恒为未初始化占位（不编造数据）。

### 3.3 Danio Arena（右栏）· 面板标题 `Danio Arena · 斑马鱼竞技场`

**画布**（5:3，`640×384` 位图）：点鱼选中（命中半径随显示宽度缩放，约 20 px），点空白取消。选中鱼高亮并叠**能量环**（能量高于阈值绿、否则红）。左下角绘制当前 `step`。

场上角色：**鱼**（两种，见下）、**猎物**、**捕食者**、**障碍**。

**鱼卡 `FISH CARD`**（点选后出现；未选时提示"点选画布上的鱼查看卡片"）：

| 读数 | 含义 |
|---|---|
| `gen` | 该鱼所属世代 |
| `energy` | 当前能量 |
| `size` | 体型 |
| `captures` | 累计捕食成功次数 |
| `steps` | 存活步数 |
| `encounters` | 累计遭遇次数（捕食口径的分母，见 §7） |
| `escapes` | 逃逸成功次数 |
| `viable` | 是否可育 |
| 第二行 | 基因鱼：`genome <id> · fitness <值>`；**规则鱼**：`EXPERT POLICY · 规则策略（无基因组）` |
| `cells` | 六类细胞计数（`sensory/prey/threat/integrator_memory/inhibitory/motor`）；实验室个体还带 `N… E… τ…` 连接组摘要 |

**演示会话里有两种鱼**（同一场景对照）：
- **基因鱼**（2 条）：有基因组、有它自己的网，点得动（点它会联动左栏 DNA 与中栏脑）。
- **规则鱼**（4 条，`ExpertPolicy`）：手写规则控制器、无基因组、鱼卡 `genome` 显示 `unknown`；作用是让画面活跃。

**`LEADERBOARD · 排行榜`**：显示前 12 名（按 `captures`、`survival_steps` 降序）；选中的鱼不在前 12 时会补在末尾；约每 2 s 刷新一次。

**`EVOLVE` 区**：

| 控件 | 作用 |
|---|---|
| 行右 `GENERATION n` | 当前世代 |
| `NEXT GENERATION` | 推进一代（同步长请求，约 2 s；进行中显示"计算中…"）：评估 → 折算适应度 $F$ → 选择繁殖 → 子代重建 Arena |
| `RESTART` | 重开一轮 episode：**步数归零、保留当前种群与 generation** |
| 推进后的读数 | `fitness`（均值）、`viable n/N`、`N̄ / Ē`（平均神经元/边数）、`bottleneck: …`（红字，命中瓶颈时） |

**`SPEED` 行**：`0.25× / 0.5× / 1× / 2× / 4× / 20×`，默认 **20×**。
- 语义：每 100 ms 的 tick 推几步；`20×` = 200 步/s，`<1×` 是把间隔拉长做慢动作。**只改推进快慢，不改模型本身**（步长/dt 不变）。
- 本档位同时是 `Playback` 视图的步速（两视图共用）。

**回合结束 → 自动进下一代**（演示默认行为）：
- 判据取先到者：① 所有鱼均已死亡；② 本轮跑满 `episode_steps`（事件 `arena.episode_end`）。
- 停留 1.2 s（先看清终帧与结局）→ 自动调会话演化一步，然后新一代开始。
- `Pause` 期间**放弃本次**自动换代（可手动点 `NEXT GENERATION`）；连续两次失败会停下等手动。
- 想重看本回合：`RESTART`。

**底部一行**：左 `session xxxxxxxx`（会话短 id）/ 右 `click a fish to inspect` 或错误信息（`⚠ …`）。

**会话生命周期（要知道的三件事）**：
1. 面板挂载即建**一条**会话：6 条鱼（4 规则 + 2 基因）、环境 `food_rich`、种子 `250927`、配置 `configs/demo_arena.yaml`（40 猎物、3600 步 ≈ 360 s 仿真时长 ⇒ 20× 下约 18 s 走完一轮）。
2. 建会话失败（后端没起/端口上是旧进程）会**每 3 s 自动重试**，画布中央显示错误与"重试中"。
3. 只切到**非 Experiment** 视图时 Arena **停止抽步**（省 CPU），切回来继续；`Reset`（底栏）= 删旧会话 + 建新会话（整会话重置，鱼全部重抽）。

## 4. 视图二：Evolution 演化（`交互与可视化.md` §8）

用途：只看**磁盘上的真实实验产物**（逐代指标曲线），不放现场动画。

**左栏 `ENVIRONMENTAL SELECTION` 表单**：

| 字段 | 说明 |
|---|---|
| `NAME` | 实验名（默认 `env-select`） |
| `SEEDS` | 种子列表，空格/逗号/分号分隔，**最多 8 个**；下方实时显示"n/8 个：… · 预计约 N s"（估算公式：`种子数 × 代数 × 20 s`，演示规模下） |
| `ENV` | `default / food_rich / predator_rich / resource_scarce` |
| `GENS` | 每个种子跑多少代（≥1） |
| `LAUNCH` | 发起后台任务，立即返回 job；**seeds 非法 / 超 8 个 / 已有任务在跑**时禁用 |
| `CANCEL` | 仅任务进行中出现；**协作式取消**，在下一个种子边界生效 |

- 演示规模是**代码固定**的 `population_size: 4`、`steps: 100`（正式实验不传这两个字段，用 `configs/evolution.yaml` 的 48 鱼与 Arena 的 `episode_steps`）。
- 任务卡片：`job_id`、状态（`queued / running / done / failed / cancelled`，颜色区分）、进度条、百分比；失败时直接显示后端 `detail.error`（不编造）。

**左栏 `SELECTION JOBS`**：本进程发起的实验列表（点一行在右下方展开 `RUN DETAIL`：`seed / gens / bottleneck / run_dir`）。

**右栏 `DISK RUNS`**：磁盘上**重启仍在**的历史 run 列表（每行 `run_id · seed N · M 代 · status`）；点一行 → 下方逐代指标；右上 `REFRESH` 手动刷新。列表为空时提示"暂无历史 run"。

**逐代指标（九项，一行两张卡片）**：

| 卡片 | 内容 |
|---|---|
| 头部（整行） | `generation 当前/总代`、`env marker ×N`（环境变更标记数，红字）、`n viable/total` |
| `P(A) / P(B) · 期望表型比例` | 两条折线 + 表型频率表（缺失显示"未记录"） |
| `FITNESS · 适应度` | 均值折线，右上 `mean ± std` |
| `FITNESS · DIST · 适应度分布` | 逐个体直方图；下方滑杆选择看哪一代 |
| `MORPHOLOGY · 形态` | `neurons` 与 `edges` 两条折线 |
| `TAU · 时间常数 τ` | τ 均值折线 |
| `VIABILITY · 可育性` | 可育比例折线，右上百分比 |

- **诚实口径**：老 producer 的 run 缺 `p_A`/`mean_*` 等字段时，一律显示"未记录"、不补 0、不画点。
- 有 run 但没有有效行时提示"该 run 没有 evolution.jsonl…"。

## 5. 视图三：Playback 手动操控（`交互与可视化.md` §10）

用途：给评委**亲手操控一条鱼**的体验；其余鱼仍由各自策略/网络驱动。**手动操控不进正式实验数据。**

| 操作 | 效果 |
|---|---|
| `← / A`、`→ / D` | 转向 $\omega=-1$ / $+1$（rad/s，后端再裁剪到 `[-1,1]`） |
| `↑ / W`、`↓ / S` | 全速 $v=1$ / 停 $v=0$；**不按上下 ⇒ 巡航 $v=0.5$** |
| 点画布上的鱼 / 点 `CONTROLLED FISH` 行按钮 | 切换被控鱼（默认第一条存活的鱼；原被控鱼死亡后自动接管） |

- `KEYS` 卡片实时显示当前 $\omega$、$v$；`READOUT · 读数` 卡片显示 `energy / captures / steps / alive`（约 1 s 刷新；未起步时提示"按 → 起步后出现读数"）。
- 会话与步速和 Arena **共用**（同一条会话、同一个 `SPEED`）；本视图激活时 Arena 让位不驱动，避免两处同时推进。
- 底栏 `Pause` 时后端不推进 ⇒ 面板提示"会话已暂停：底栏按 Release 恢复推进，再操控"。
- 若显示红框"后端版本落后…"，说明端口上是未升级的旧进程，重启后端即可（`/v1/health.manual_control` 能力位，见 §1.3）。

## 7. 读数词典与引用口径

**单位/符号**：`N` 神经元数、`E` 边数、`τ` 时间常数、`ω` 转向角速度（rad/s）、`v` 速度（世界单位/秒）、`q(S)` motif 亲和度（8 维）、`F` 适应度、`step` 仿真步、`generation` 世代、`episode` 一轮（回合）。

**引用数字前必须说清的口径**（页面上同时存在多个"捕获"类数字）：

- 口语的"捕获率"在本项目有**三个不同口径**（绝对速率 / 个体接触转化率 / 汇总比值），实测可差数倍；引用任何一个都**必须说明是哪一个**。
- 捕食的**分母（遭遇数）严重右偏**：少数个体长期蹲守会把均值拉高，不能只报一个均值。
- `energy_efficiency` 是**每步速率**（约 $10^{-3}$、非正），**不可**与 0–1 的比值同轴比较。
- 页面是**机制链路与现场观测**：学习前后对照、基线对照在论文中仍是待补；`FLOPs`、推理速度、能耗**尚未测量**，被问到就直说未测。

## 8. 常见故障与处理

| 症状 | 原因 | 处理 |
|---|---|---|
| 顶栏健康点红；Arena 中央显示"构建种群中…"或错误 + "重试中" | 后端没起 / 端口上是旧进程 | 起或重启后端；前端会每 3 s 自动重试 |
| Playback 按键毫无反应，且出现红框告警 | 后端版本落后（不支持手动动作参数） | 重启后端 |
| `LAUNCH` 灰 | `SEEDS` 为空 / 非整数 / 超过 8 个 / 已有任务在跑 | 改 seeds 或等当前任务结束（或 `CANCEL`） |
| 指标卡显示"未记录" | 老 run 缺该字段（不是 bug） | 换用本版本产生的 run |
| 帧率低、风扇响 | 高步速 + 多面板同时刷新 | 切到非 Experiment 视图（Arena 自动停抽步）或把 `SPEED` 降到 `1×`/`0.25×` |
| 不知道 `Reset` / `RESTART` / `NEXT GENERATION` 的区别 | — | `NEXT GENERATION`=推进一代；`RESTART`=重开本轮（保留种群与 generation）；`Reset`（底栏）=整会话重置（重新建鱼、世代归零） |
| 一轮结束不想自动换代 | — | 底栏 `Pause`（暂停期间放弃本次自动换代），或用 `RESTART` 重看本轮 |
| 后端起不来、提示端口占用 | 8000 被占 | 换端口：`EVOGENESIS_PORT=8123 make demo`，或先找出占用进程（`lsof -ti:8000` 会同时列出持有代理连接的 vite，别误杀 dev server） |

## 9. 演示红线（不要做的事）

1. **不现场改 `configs/`、不改种子**：前端唯一硬编码种子是 `250927`，与 `configs/demo_seed.yaml` 一致；正式实验种子是另一套（`configs/experiment_seeds.yaml`），两者不得混用。
2. **不找不存在的功能**：`Breed`、`Before/After`、`Virtual CRISPR` 等界面已删除（`src/api/lab.ts` 仍导出 `breed()`，但**没有 UI 入口**）；不要在现场翻。
3. **不引用无凭证数字**：如"混合种群捕获 20/76/70"这类只在临时探针里出现、没有落盘结果的数字。
4. **不把演示规模当正式口径**：Arena 演示是 4 规则+2 基因鱼 × 3600 步的短回合；Evolution 表单的 `4 鱼 × 100 步` 也是演示规模。
5. **手动操控数据不进正式结果**（Playback 只驱动当前会话，不落记录）。
6. **不要拿界面当论文证据**：本页面向评委展示**链路与真实中间状态**；论文结论以 `results/` 的落盘产物为准。
