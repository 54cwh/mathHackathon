# 演示讲稿（约 9 分钟）

> 用途：现场按本稿走一遍网页，**每一幕都落到一句研究结论**。
> 判据（用户 2026-09-27）：**若某个功能无法在这一稿里把观众带到"更深入的理解"，则该功能要么不需要、要么设计有问题。** 取舍表见文末。
> 演示配置：会话用 `configs/demo_arena.yaml`（4 鱼 / 40 猎物 / 3600 步，`hz=10`），前端步速默认 `20×`（200 步/s；一轮跑完后在 EVOLVE 区点 `RESTART · 重开一轮` 手动继续，种群与 generation 不丢）；正式实验用 `default_arena.yaml`（12 鱼 / 600 步）。

---

## 幕 0 · 立论（20 s，不动鼠标）

> 我们做的不是"把模型接个网页"，而是**一条从基因到行为的可验证链路**：
> 二倍体基因组 → 调控网络（GRN）→ 发育出连接组 → **每条鱼用它自己的脑**在生态里活动 → 选择繁殖出下一代。
 > 屏幕上所有画面都来自这条链路的**真实中间状态**，不是示意动画。
>
> （两种推进方式：顶栏 `AUTO` 一键按脚本跑完、门控未过即停；或按下面的幕序手动点——顶栏 `Next` 负责推进段落。底栏 `Pause · 暂停` 可随时停下来细看。）

## 幕 1 · 基因组是可控输入（60 s）— `DNA2Brain Lab 基因 → 大脑`

**操作**：指四条单倍体条带 → 拖 `POS` 指定位点 → `MUTATE · 突变` → `DEVELOP · 发育`。

**台词**：
> 左边这一栏是输入。四条单倍体（P0/P1 × 母源/父源），条带上的每个字母都是真实碱基——**同源位点之间不是碱基配对**，本模型的两条链是各自独立的随机序列。
> 我在这里改**一个**碱基（直接点碱基条上的字母即可定位，或用 `POS` 滑杆），然后点 `MUTATE · 突变`、再 `DEVELOP · 发育`；`PHENOTYPE 表型` 会实时重算——改前改后的差异就看这几个数的变化。

**建立的认知**：基因是**可精确编辑、可复现**的输入。
**落到研究**：实验前提——输入可控，单点编辑产生可测的表型变化（相同种子逐位可复现）。

## 幕 2 · 发育不是黑盒（90 s）— `Brain Forge 脑发育`

**操作**：指阶段轨 `MOTIF → q(S) → GRN → DIVISION → DIFFERENTIATION → CONNECTIONS → DANIONET`；拖时间线看 `GRN` **逐渐点亮**、`DIVISION` 时**新生子代标绿**、`CONNECTIONS` 的 `P`（概率场）与 `A`（真实邻接）交替；指右下 `ACTIVATION 神经活动` 的五类读数。

**台词**：
> 这是我们相对"端到端黑盒"的核心区别：**中间每一步都能指认**。
> 注意两点我们没有造假：连接是"**概率场 p** → **一次采样 A**"，模型里没有"逐步长边"这个过程；增殖在模型里是**一轮**（每个前体至多分裂一次），所以神经元是**一次跳变**——我们把新生子代标出来，而不是编一个渐变。
> 右边这五个读数（sensory / prey / threat / integrator / 左右 motor）是按**这条鱼自己的细胞类型**把激活分组算出来的，不是装饰。

**落到研究**：中间过程可指认、可复算；不做模型里不存在的动画。

## 幕 3 · 每条鱼有自己的脑、且真的在觅食（90 s）— `Danio Arena 斑马鱼竞技场`

**操作**：点 Arena 里某一条鱼 → 右侧 `FISH CARD 个体卡片` 显示它的 `genome / N·E / τ`；等几秒，指出捕食事件（猎物数下降、`LEADERBOARD 排行榜` 变化）。

**台词**：
> 这 4 条鱼不是"专家策略"背景板——**每条鱼由它自己基因发育出的网络驱动**。点它，左栏能回看它的 DNA，右栏能回看它的脑——这就是"基因→脑→行为"闭环在界面上的证据。
> 我们这个演示配置是 4 鱼 / 40 猎物、步速 20×；放宽了能量预算、`hz` 减半（每步位移翻倍），并让**鱼(0.44–0.50)明显比食物(0.20)快**、但又**在捕食者追速 0.70 之下**（所以吃与被吃都看得见）。默认 12 鱼 × 30 秒实测**捕食 0 次**，看不到"吃东西"，所以专门调了这个演示档。**鱼少了会自动补一条**，场上不会空。

**落到研究**：同一套基因→发育→网络，驱动真实行为；个体点得动、对得上。

## 幕 4 · 演化是逐代的（60 s）— Arena 的 `EVOLVE 演化`

**操作**：点 `NEXT GENERATION · 下一代` → 顶栏 `Generation 0 → 1`，种群换代，当代 `fitness / viable / N̄ / Ē` 就地更新。

**台词**：
> 演化不是"提交 20 代等进度条"，而是**一代一幕、可打断**：评估 → 折算适应度 → 选择繁殖 → 用可育子代重建种群。这一代就发生在我们眼前。
> 一轮（episode）跑完画面会停住——点旁边的 `RESTART · 重开一轮` 接着看，**种群与 generation 都不丢**（底部 `Reset` 才是整会话重置）。

**落到研究**：选择 / 繁殖 / 漂变按 `configs/evolution.yaml` 真实执行。

## 幕 5 · 正式实验的定量证据（60 s）— `Evolution 演化` 视图

> ⚠️ 先把话说清楚，否则观众会混：**这里是正式实验，不是刚才那 4 条鱼**。

**操作**（两条都走）：
1. **现场发起一个小实验**：左栏 `ENVIRONMENTAL SELECTION` 用默认（1 种子 × 1 代，演示规模 4 鱼 × 100 步）→ 点 `LAUNCH · 启动` → 看下方进度跑完（约 20 s；先按底栏 `Pause` 会更快）→ 右栏 `DISK RUNS` 顶部出现这条新 run。
2. 在 `DISK RUNS 历史运行` 列表里点它（或点更长的 `demo-evo-s250927`）→ 看下面的逐代曲线。

**台词**：
> 刚才实验台看到的是"**一代**"；这里放的是**跑完很多代的正式实验**，而且都是**磁盘上的真实产物**，重启也在、可复跑。
> 这块 `ENVIRONMENTAL SELECTION` 就是**发起正式实验**的入口：我现场点一下 `LAUNCH`，它就在后台按种子逐代跑，跑完直接落成一个 run（右侧列表最上面那条就是它）。种子框下面的"预计耗时"是照演示规模算的。
> - `P(A) / P(B) 期望表型比例（基因型读出）`：由基因组直接读出的两个阈值表型在各代的比例——看选择有没有把群体推过去；
> - `FITNESS 适应度`：逐代均值 + 某一代的分布——看均值涨没涨、方差收没收；
> - `MORPHOLOGY 形态`：平均神经元 / 连接数 / τ——看形态是否也在被选择；
> - `VIABILITY 可育性`：可育率，是我们的瓶颈指标，跌破会触发 `evolution.population_bottleneck` 停代。
> 一句话：**出示的是逐代量化轨迹，每条都能回到磁盘上的原始产物。**

**被追问时**：
> "数据怎么来？" → 每代一个目录 + 一行 `evolution.jsonl`，前端只读这些文件。
> "和那 4 条鱼什么关系？" → 同一套代循环代码（`setup_evolution` / `one_generation`）；一个在界面里一步步点，一个在后台整段跑并落盘。

## 幕 6 · 评委上手体验（60 s，可选）— `Playback 手动操控`

**用途**：给评委**亲手操作**，不是研究证据（`交互与可视化.md` §10 明说它不进正式实验数据）。

**操作**：点底栏 `Playback · 手动操控` → 用 `← → ↑ ↓`（或 `A D W S`）操控一条鱼；**点画布上的鱼**或在 `CONTROLLED FISH 被控鱼` 列表里点一条来切换被控对象。

**台词**：
> 最后留一个操场给各位：你们可以直接操控一条鱼，其余鱼仍由它们各自的网络驱动；**步速与实验台共用同一档（默认 20×）**。它不是实验数据的一部分——**是让你们感受这条鱼"在想什么、能不能逃、能不能吃"**。

## 幕 7 · 收尾（20 s）

> 我们的贡献不是"更好看的界面"，而是：**可控输入 + 可指认的中间过程 + 每条鱼各自的脑 + 逐代可验证的演化**。界面只做了最后一件事——把这条链路**指给你看**。

# 复现 / 复跑

```bash
make env            # uv sync（editable）
make demo           # 构建前端 + 起 API，浏览器开 http://127.0.0.1:8000
# 或分别：
uv run uvicorn evogenesis.api.app:app --host 127.0.0.1 --port 8000   # 改完后端必须重启（旧进程会静默忽略新字段）
cd frontend && npm run dev                                          # 5173（proxy → 8000）
```

- 演示种子：`configs/demo_seed.yaml::master_seed = 250927`（前端 `MASTER_SEED`）。
- 演示会话：`configs/demo_arena.yaml`（4 鱼 / 40 猎物 / 3600 步，`hz=10`，鱼速上限 0.50、食物 0.20、捕食者追速 0.70）；前端步速默认 `20×`（可在 Arena 底栏切 `0.25×–20×`）；一轮跑完点 EVOLVE 区的 `RESTART · 重开一轮`。
- **演示 run（Evolution 视图要用，`results/` 不入库）**：`uv run python scripts/run_baselines.py` 之外，本演示用下面这段生成 `demo-evo-s250927`（12 鱼 × 15 代 × 150 步，约 1 分钟）：
  ```bash
  uv run python - <<'EOF'
  from dataclasses import replace
  from evogenesis.arena.config import load_arena_config
  from evogenesis.evolution.config import load_evolution_config
  from evogenesis.experiment import runlayout
  from evogenesis.experiment.evolution_run import run_evolution
  from evogenesis.pipeline import load_model_chain_config
  chain = load_model_chain_config("configs/default_model.yaml")
  arena = load_arena_config("configs/demo_arena.yaml")
  evo = load_evolution_config("configs/evolution.yaml").model_copy(update={"population_size": 12})
  rd = runlayout.create_run_dir(experiment_id="demo-evo", seed=250927,
        config_path="configs/demo_arena.yaml", out_root="results/runs",
        extra_configs=("configs/default_model.yaml", "configs/evolution.yaml"))
  run_evolution(experiment_id="demo-evo", master_seed=250927, generations=15, chain=chain,
        arena_config=arena, evolution_config=evo, run_dir=rd, steps=150, environment_id="default")
  EOF
  ```
- 会话内每代步数：`configs/demo_session.yaml::evolution_steps = 100`。
- 正式实验：`configs/experiment.yaml` / `configs/evolution.yaml` / `configs/default_arena.yaml`。
