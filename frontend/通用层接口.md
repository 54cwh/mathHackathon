# 前端通用层接口

> **管辖范围**：本文件是前端**通用层的接口参考**——每个模块的公开导出、签名、用法片段与禁令。**不拥有**设计理由与依据（`frontend/通用层设计.md`）、面板内的交互与视觉内容（`frontend/交互与可视化.md`）、10 条几何/视觉规则（`frontend/交互与可视化.md` 附录 A）、技术栈版本（`frontend/README.md`）、后端契约（`api/API接口.md`、`schemas/`）。
> **风格裁决与合并记录**：唯一出处为 `frontend/交互与可视化.md` §14 / §15。
> **归属**：风格设计（品牌色板/字体/像素风）owner = 李辰钊；代码结构与接口 owner = 池伟豪。
> **状态**：v1.2（2026-09-27 演示重构：`store/ui.ts` 成为**单一真相**，`store/labBus.ts` 并入）。品牌 24 色**已冻结**（`palette.ts`）。
> **用法**：写任何面板前先读本文件；面板里**只准引用**通用层，不准出现颜色/圆角/几何字面量（`npm run lint:design` 强制）。

## 0. 30 秒上手：一个面板的标准写法

```tsx
import { Panel } from "@/components/Panel";
import { ARENA } from "@/design/palette";
import { CANVAS, arenaAspect, sx, sy } from "@/design/geometry";
import { useUiStore } from "@/store/ui";
import { getSnapshot, type ArenaSnapshot } from "@/api/arena";

export function MyPanel() {
  const sessionId = useUiStore((s) => s.sessionId);       // 只读低频摘要
  const setSelectedFish = useUiStore((s) => s.setSelectedFish);
  // …20Hz 热路径用 useRef + requestAnimationFrame/Canvas，不走 React（README 防坑 3）
  return (
    <Panel title="My Panel">
      <div style={{ aspectRatio: arenaAspect() }} />
    </Panel>
  );
}
```

要点：**布局用 `Panel`/`AppFrame`；颜色用 `design/palette`；几何用 `design/geometry`；契约类型用 `api/types`；网络用 `api/arena`（REST）与 `api/ws`（推送）；全局低频状态用 `store/ui`。**

## 1. `src/design/geometry.ts` — 几何（唯一来源）

| 导出 | 类型 | 值 / 说明 |
|---|---|---|
| `FRAME_RATIO` | `readonly [3, 2]` | 整体帧比例（规则 1） |
| `ARENA_RATIO` | `readonly [5, 3]` | 竞技场视口比例（规则 3） |
| `WORLD` | `{ w: 100, h: 60 }` | 世界坐标（arena §2） |
| `CANVAS` | `{ w: 640, h: 384 }` | 竞技场位图（比例 = `ARENA_RATIO`） |
| `DIVIDER_PX` | `1` | 分割线宽（规则 5） |
| `frameAspect()` | `string` | → `"3 / 2"`，给 `style.aspectRatio` |
| `frameWidth()` | `string` | → pillarbox 宽度表达式，给 `style.width` |
| `arenaAspect()` | `string` | → `"5 / 3"` |
| `sx(x)` / `sy(y)` / `sr(r)` | `number` | 世界→画布，**含 `Math.round`**（规则 9(b)） |

```tsx
<div style={{ aspectRatio: arenaAspect() }}>
  <canvas width={CANVAS.w} height={CANVAS.h} className="h-full w-full" />
</div>
```
**禁**：在面板里重算比例/坐标（如 `(x/100)*640`）——一律调 `sx/sy/sr`。

## 2. `src/design/palette.ts` — 颜色（唯一来源，owner：李辰钊）

| 导出 | 说明 |

| `BrandColor` | `keyof typeof BRAND` |
| `ARENA` | 竞技场角色映射（`canvas/obstacleDark/obstacleLight/prey/predator/fishSelected/fishUnselected/outline/energyOk/energyLow/hudText`），全部指回 `BRAND` |
| `RADIUS` | `"0"`（无圆角基准） |

两种合法写法（**禁止 hex 字面量**）：

```tsx
ctx.fillStyle = ARENA.prey;                 // Canvas：取角色常量
<span className="bg-brand-ink text-brand-foam" />   // DOM：Tailwind `brand-*`（来自 colors.brand）
```
**已冻结**（2026-09-26 品牌 24 色板，`ui_reference_prompts.md §候选色板`）。改色只改 `palette.ts`（须同步素材提示词 `{色板}`）。
⚠️ 相对改造前的**可见配色变化**：画布底 `#0B1220`→`ink`、鱼改为 `fishBlue`/`amber` 填充 + `ink` 统一轮廓、猎物→`lightGrass`、捕食者→`dangerRed`。

## 3. `src/design/tokens.ts` — shell CSS 变量（唯一来源 + 生成器）

| 导出 | 说明 |
|---|---|
| `tokens` | 22 个 shell 颜色 token（**HSL 裸三元组**，如 `"213 29% 6%"`） |
| `TokenName` | `keyof typeof tokens` |
| `RADIUS` | `"0"`（规则 4） |
| `BORDER_RADIUS_SCALE` | Tailwind `borderRadius` 全 0 档 |
| `CSS_TOKENS_BEGIN` / `CSS_TOKENS_END` | `index.css` 生成块标记 |
| `toCssRootBlock()` | 渲染 `:root` 生成块 |
| `toTailwindColors()` | 渲染 Tailwind `colors` 映射 |

消费方式（**不要手写副本**）：
- `tailwind.config.ts` 直接 `import { toTailwindColors, BORDER_RADIUS_SCALE }`；
- `src/index.css` 的 token 块由 `npm run gen:design` 写入（标记之间），`npm run lint:design` 做**漂移校验**。

**改 token 的姿势**：只改 `tokens.ts` → `npm run gen:design` → 提交。**不要**直接编辑 `index.css` 的生成块。

## 4. 字体：`src/design/typography.ts` + `src/design/fonts.css`

| 导出 / 入口 | 类型 | 说明 |
|---|---|---|
| `FONT_TEXT_STACK` | `string[]` | 正文栈（`Inter, system-ui, sans-serif`） |
| `FONT_MONO_STACK` | `string[]` | 等宽栈（DNA / 数值） |
| `design/fonts.css` | CSS | `@font-face` 自托管（Inter / JetBrains Mono / Press Start 2P），由 `index.css` `@import` |
| `.font-pixel` | CSS class | 像素字体作用域；**只加英文标签/标题**，数值走 `font-mono` |

`sans`/`mono` 由 `tailwind.config.ts` 消费；像素字体不带进 Tailwind（`-webkit-font-smoothing` 是 CSS 副作用，owner = `index.css`）。

## 6. `src/api/` — 契约与通道

### `types.ts`（契约类型，`snake_case`，唯一契约定义处）
对齐 `api/schemas.py`：`Environment`、`JobStatusKind`、`JobStatus`、`Page<T>`、`SessionCreate`、`SessionSummary`、`FishState`/`PreyState`/`PredatorState`/`ObstacleState`/`ArenaEvent`/`ArenaSnapshot`、`FishCard`、`Leaderboard`/`LeaderboardEntry`、`Base`、`GenomeCreate`/`GenomeRecord`、`MutationRequest`/`MutationResult`、`DevelopmentRequest`/`DevelopmentResult`（含 `DevelopmentTrace`/`DevelopmentPhenotype`）、`BreedingRequest`/`BreedingResult`、`MutationDiff`、`EnvironmentalSelectionLaunch`/`…Summary`/`…Detail`、`Health`。

### REST 客户端（按资源分文件，一个资源一个 owner）
| 文件 | 覆盖端点（`api/API接口.md`） |
|---|---|
| `arena.ts` | 会话 §1.1–§1.9：`createSession(masterSeed?, environment?, driving?)`、`getSession`、`resetSession`、`deleteSession`、`release(id, steps?, useExpert?, control?)`（`control: ManualControl = {fish_id, omega, speed}`，§1.6 Manual Control）、`pauseSession`（§1.7 toggle）、`getSnapshot`、`getFishCard(id, fishId)`、`getLeaderboard`；`MASTER_SEED = 250927`。`driving = { model_driven, checkpoint_path }` |
| `lab.ts` | 基因组实验室 §2.3：`createGenome(seed?)`、`getGenome(id)`、`mutateGenome(id, {position, base})`、`develop({genome_id, seed})`、`breed({genome_a, genome_b, n_offspring})` |
| `selections.ts` | Experiment F §2.2：`launchSelection(launch)`、`listSelections(limit?, cursor?)`、`getSelection(id)`、`getJob(id)`、`cancelJob(id)`；会话内演化 `evolveSession(id, generations?)` (§2.3) |
| `runs.ts` | 磁盘 run（§2.4）：`listRuns(limit?, cursor?)`、`getRunEvolution(runId)` |
| `health.ts` | `getHealth()`（§1.10） |
| `http.ts` | `req<T>(path, init?)`——**唯一** fetch 出口，非 2xx 抛后端 `detail`（§4 RFC 7807） |

类型经 `export type { … }` 转发；面板**只**从这些模块取 REST 能力。

消费者现状：`DNA2BrainPanel`→`lab.ts`；`EvolutionDashboardPanel`→`selections.ts`；
`DanioArenaPanel`→`arena.ts`（会话 + `getFishCard`/`getLeaderboard`）+ `ws.ts`（`arena.fish_state` 鱼层，
场景层每 0.5s 走一次 snapshot）；
`TopBar`→`health.ts` + `store.stats.environment`；`BottomBar`→`pauseSession`（后端 toggle）；
`PlaybackPanel`（Manual Control 操场）→`arena.ts`（`release` 带 `ManualControl`）+ `ArenaScene`。
`EvolutionDashboardPanel`→`selections.ts`（启动/取消/详情）+ `runs.ts`（§8 指标，`EvolutionMetrics` 子组件）。

### `visuals/ArenaScene.ts`（Arena 画面原语，Arena 与 Playback 共用）
`ArenaScene`（`step` + `fish`/`prey`/`predators`/`obstacles`）、`drawArenaScene(ctx, scene, selectedFishId?)`、`hitTestFish(scene, mx, my, maxDist)`、`fishHitRadius(displayWidth)`、`fillBackdrop(ctx)`。
**禁**：面板各写一份画法或命中判定（两处必须同源，否则回放里点不到鱼）。

### `ws.ts`（推送，唯一信封 owner）
```ts
import { subscribe } from "@/api/ws";

const off = subscribe(sessionId, {
  fishState: (p) => { /* p.fish: Record<string, FishState> */ },
  events: (p) => { /* p.events: ArenaEvent[] */ },
  jobProgress: (p) => { /* p.job_id / status / progress */ },
  brainActivation: (p) => { /* p.fish: Record<string, number[]> */ },
});
// 卸载：off()
```
`WsEnvelope<T>`、`FishStatePayload`、`ArenaEventsPayload`、`JobProgressPayload`、`BrainActivationPayload`、`WsHandlers`。`connectWs()` 是底层原语（一般不用）。**禁**：面板自己 `new WebSocket`。
消费者现状：`BrainForgePanel` 订阅 `brainActivation`（无帧时走 `StatusPlaceholder`；仅**模型驱动**会话会推送，见 `API接口.md` §3/§7.2）。

## 7. `src/store/ui.ts` — 全局状态（**单一真相**）

`useUiStore` 是前端**唯一共享状态源**：会话身份、「当前个体」、演示流程、发育产物都只在这里。面板**只读订阅**，不得用 `useState` 自持副本（`通用层设计.md` §3 铁律 6）；跨面板通信一律经 store，不再有旁路总线（`store/labBus.ts` 已于 2026-09-27 并入本文件）。

**壳层（shell）**：`running`、`activeView: ViewId`、`stats: ArenaStats | null`、`resetNonce`；动作 `setRunning/toggleRunning`、`setActiveView`、`setStats`、`bumpReset`。`ViewId = "evolution" | "experiment" | "playback" | "compare"`（`compare` = COMPARE 段视图，`交互与可视化.md` §1；其余为自由探索视图）。

**领域层（domain）——「当前个体」与演示流程**（类型：`api/types.ts` 的稳定 ID 类型；本地组合类型在此定义）：

| 字段 | 类型 | 含义 |
|---|---|---|
| `journey` | `JourneyStage` | 演示流程当前段：`"seed" \| "genome" \| "develop" \| "arena" \| "evolve" \| "compare"`（`交互与可视化.md` §1 导演线） |
| `activeGenomeId` | `string \| null` | 当前基因组（稳定 ID，`core §3.1`） |
| `activeIndividual` | `SpawnedIndividual \| null` | 该基因组在 Arena 的个体；实验室个体 `fish_id == genome_id` |
| `activeRunId` | `string \| null` | 当前实验 run（磁盘 run_id 或会话内 job id） |
| `generation` | `number` | 当前展示的代（逐代推进用） |
| `evolutionBusy` | `boolean` | 会话内演化一步进行中（长请求的"进行中"反馈） |
| `development` | `LabDevelopment \| null` | 最近一次发育产物；`{ genomeId, result, trace, seq }`。`seq` 为发布序号，订阅方据此判断"新的一次发育" |
| `individuals` | `SpawnedIndividual[]` | 会话内**整种群**个体（初始基因组种群 ∪ §1.11 追加；`GET /v1/sessions/{id}/individuals`）。供去重与导演线门控；**不枚举渲染**（选个体走点击 Arena 画布上的鱼） |
| `focusNonce` | `number` | 焦点事件计数；`focusGenome()` 置 `activeGenomeId` 并自增，使"同一个体再点一次"也能被订阅到 |
| `intent` | `{ stage: JourneyStage; nonce: number } \| null` | 导演线「下一步」的下发意图；`requestIntent(stage)` 置 `journey=stage` 并自增 `nonce`，目标段面板用 ref 去重后执行该段动作（门控与动作见 `交互与可视化.md` §1 状态机表） |
| `autoPlay` | `boolean` | AUTO DEMO 开关：定时循环「下一步」，门控未通过即停在该段 |

动作：`setJourney/nextStage/prevStage`、`requestIntent(stage)`、`setAutoPlay`、`setActiveGenome`、`setActiveIndividual`、`setActiveRun`、`setGeneration`、`publishDevelopment(genomeId, result, trace)`、`addIndividual(individual)`、`setIndividuals(list)`、`focusGenome(genomeId)`、`resetJourney`。门控判据导出为纯函数 `isStageReady(state, stage)`（`交互与可视化.md` §1）。另保留 `sessionId`、`selectedFishId` 及其 setter。
**禁**：把 20Hz 数据放 store（README 防坑 3：逐帧鱼层用 `useRef` + `requestAnimationFrame`）；面板自持上述字段的副本。

## 8. npm 脚本与强制

| 脚本 | 作用 |
|---|---|
| `npm run lint:design` | 扫 `src/**` 违规样式 + **校验 index.css 与 tokens.ts 一致**（失败即非零退出） |
| `npm run gen:design` | 从 `tokens.ts` 重写 `index.css` token 块 |
| `npm run build` / `npm run lint` | 类型/构建、eslint |

**违规触发**：字面 `#hex` / `rgb(` / `hsl(`、`{gray,slate,…}-数字`、`rounded*`、`shadow*`、`blur*`、`gradient`、`transition-colors`。豁免：`design/palette.ts`、`design/tokens.ts`、`index.css`。

## 9. 扩展点（新增东西时改哪里）

| 要加 | 改哪 |
|---|---|
| 颜色 / 主题 token | `design/palette.ts` 或 `design/tokens.ts` → `npm run gen:design` |
| 几何常量 / 比例 | `design/geometry.ts` |
| 字体 | `design/typography.ts` |
| 后端端点 / 类型 | 类型归 `api/types.ts`；端点加到对应资源文件，无则新建 `api/<resource>.ts`（见 §6 表） |
| 推送信道 | `api/ws.ts`（加 `type` → payload 接口 → `subscribe` 分支） |
| 视图 | `store/ui.ts` 的 `ViewId` + `App.tsx` 渲染 + `ViewTabs` 文案 |
| 演示流程段 / 当前个体 | `store/ui.ts` 的 `JourneyStage` 与 domain 字段（§7）；UI 在 §1 导演线 |
| 新面板 | `src/panels/<Name>Panel.tsx`，套 `Panel` 外壳，只引用通用层 |

**新增文件自查**：① 有无颜色/几何字面量？② 是否 import 了通用层而非自己造？③ `npm run lint:design && npm run lint && npm run build` 是否全绿？
