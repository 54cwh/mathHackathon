# 前端通用层接口

> **管辖范围**：本文件是前端**通用层的接口参考**——每个模块的公开导出、签名、用法片段与禁令。**不拥有**设计理由与依据（`frontend/通用层设计.md`）、面板内的交互与视觉内容（`frontend/交互与可视化.md`）、10 条几何/视觉规则（`frontend/视觉规范审计.md`）、技术栈版本（`frontend/README.md`）、后端契约（`api/API接口.md`、`schemas/`）。
> **状态**：v1.0（2026-09-27）。颜色/字体值标 `草案待确认`（等 `交互与可视化.md §13` 视觉冻结）。
> **用法**：写任何面板前先读本文件；面板里**只准引用**通用层，不准出现颜色/圆角/几何字面量（`npm run lint:design` 强制）。

## 0. 30 秒上手：一个面板的标准写法

```tsx
import { Panel } from "@/components/Panel";
import { arena as arenaColor } from "@/design/palette";
import { CANVAS, arenaAspect, sx, sy } from "@/design/geometry";
import { useUiStore } from "@/store/ui";
import { getSnapshot, type ArenaSnapshot } from "@/api/arena";

export function MyPanel() {
  const sessionId = useUiStore((s) => s.sessionId);       // 只读低频摘要
  const setSelectedFish = useUiStore((s) => s.setSelectedFish);
  // …20Hz 热路径用 useRef + requestAnimationFrame/Canvas，不走 React（README 防坑 3）
  return (
    <Panel title="My Panel">
      <div style={{ aspectRatio: arenaAspect() }} />
    </Panel>
  );
}
```

要点：**布局用 `Panel`/`AppFrame`；颜色用 `design/palette`；几何用 `design/geometry`；契约类型用 `api/types`；网络用 `api/arena`（REST）与 `api/ws`（推送）；全局低频状态用 `store/ui`。**

## 1. `src/design/geometry.ts` — 几何（唯一来源）

| 导出 | 类型 | 值 / 说明 |
|---|---|---|
| `FRAME_RATIO` | `readonly [3, 2]` | 整体帧比例（规则 1） |
| `ARENA_RATIO` | `readonly [5, 3]` | 竞技场视口比例（规则 3） |
| `WORLD` | `{ w: 100, h: 60 }` | 世界坐标（arena §2） |
| `CANVAS` | `{ w: 640, h: 384 }` | 竞技场位图（比例 = `ARENA_RATIO`） |
| `DIVIDER_PX` | `1` | 分割线宽（规则 5） |
| `frameAspect()` | `string` | → `"3 / 2"`，给 `style.aspectRatio` |
| `frameWidth()` | `string` | → pillarbox 宽度表达式，给 `style.width` |
| `arenaAspect()` | `string` | → `"5 / 3"` |
| `sx(x)` / `sy(y)` / `sr(r)` | `number` | 世界→画布，**含 `Math.round`**（规则 9(b)） |

```tsx
<div style={{ aspectRatio: arenaAspect() }}>
  <canvas width={CANVAS.w} height={CANVAS.h} className="h-full w-full" />
</div>
```
**禁**：在面板里重算比例/坐标（如 `(x/100)*640`）——一律调 `sx/sy/sr`。

## 2. `src/design/palette.ts` — 颜色（唯一来源）

| 导出 | 说明 |
|---|---|
| `palette` | 24 色**候选板**（键见下）；来源 `ui_reference_prompts.md §候选色板` |
| `PaletteName` | `keyof typeof palette` |
| `arena` | 竞技场画布色（`bg/obstacleFill/obstacleStroke/prey/predatorFill/predatorStroke/fishFill/fishStroke/selectedFill/selectedStroke/energyOk/energyLow`） |
| `ArenaColor` | `keyof typeof arena` |

`palette` 键：`ink, slateShadow, blueGrey, deepWater, midWater, shallowWater, foam, deepGrass, grassGreen, lightGrass, fishNavy, fishBlue, barkDark, woodBrown, sandWarm, sandLight, amber, coralOrange, dangerRed, mutationViolet, white, bone, stoneGrey, stoneShadow`。

```tsx
ctx.fillStyle = arenaColor.prey;      // canvas
// DOM 用语义 class（bg-card / text-muted-foreground …），不要 hex
```
**状态 `草案待确认`**：`palette` 是候选、`arena` 尚未映射到 `palette`；视觉冻结后**只改此文件**。

## 3. `src/design/tokens.ts` — shell CSS 变量（唯一来源 + 生成器）

| 导出 | 说明 |
|---|---|
| `tokens` | 22 个 shell 颜色 token（**HSL 裸三元组**，如 `"213 29% 6%"`） |
| `TokenName` | `keyof typeof tokens` |
| `RADIUS` | `"0"`（规则 4） |
| `BORDER_RADIUS_SCALE` | Tailwind `borderRadius` 全 0 档 |
| `CSS_TOKENS_BEGIN` / `CSS_TOKENS_END` | `index.css` 生成块标记 |
| `toCssRootBlock()` | 渲染 `:root` 生成块 |
| `toTailwindColors()` | 渲染 Tailwind `colors` 映射 |

消费方式（**不要手写副本**）：
- `tailwind.config.ts` 直接 `import { toTailwindColors, BORDER_RADIUS_SCALE }`；
- `src/index.css` 的 token 块由 `npm run gen:design` 写入（标记之间），`npm run lint:design` 做**漂移校验**。

**改 token 的姿势**：只改 `tokens.ts` → `npm run gen:design` → 提交。**不要**直接编辑 `index.css` 的生成块。

## 4. `src/design/typography.ts`

| 导出 | 类型 | 说明 |
|---|---|---|
| `FONT_TEXT_STACK` | `string[]` | 正文（`Inter, system-ui, sans-serif`） |
| `FONT_MONO_STACK` | `string[]` | 等宽（DNA / 数值） |

被 `tailwind.config.ts` 消费为 `font-sans` / `font-mono`。像素字体未选型（选后只用于标签）。

## 5. `src/components/` — 布局

| 组件 | Props | 职责 |
|---|---|---|
| `AppFrame` | `{ children }` | 3:2 + pillarbox（规则 1 唯一 owner） |
| `TopBar` | — | 顶栏；读 `store.stats` |
| `BottomBar` | — | Pause/Release · Reset · `ViewTabs` |
| `ViewTabs` | — | 真 tab，读写 `store.activeView` |
| `StatusPlaceholder` | `{ label }` | 占位块（等 §4 口径） |
| `Panel` | `{ title, icon?, className?, children? }` | 面板外壳；**无圆角、不画栏间线**（线由父级 grid 拥有） |

```tsx
<main className="grid min-h-0 flex-1 grid-cols-3 divide-x divide-border border border-border">
  <Panel title="A">…</Panel>
  <Panel title="B">…</Panel>
  <Panel title="C">…</Panel>
</main>
```
**禁**：面板自带外边框/栏间线（会与父级 `divide-x` 形成双线）。

## 6. `src/api/` — 契约与通道

### `types.ts`（契约类型，`snake_case`）
`Environment`（`"default" | "food_rich" | "predator_rich" | "resource_scarce"`）、`SessionSummary`、`FishState`、`PreyState`、`PredatorState`、`ObstacleState`、`ArenaEvent`、`ArenaSnapshot`。

### `arena.ts`（REST，唯一客户端）
`MASTER_SEED = 250927`（Live Demo 唯一种子）；`createSession(masterSeed?, environment?)`、`getSession(id)`、`resetSession(id)`、`deleteSession(id)`、`release(id, steps?, useExpert?)`、`getSnapshot(id)`。类型经 `export type { … }` 转发。

### `ws.ts`（推送，唯一信封 owner）
```ts
import { subscribe } from "@/api/ws";

const off = subscribe(sessionId, {
  fishState: (p) => { /* p.fish: Record<string, FishState> */ },
  events: (p) => { /* p.events: ArenaEvent[] */ },
  jobProgress: (p) => { /* p.job_id / status / progress */ },
  brainActivation: (p) => { /* p.fish: Record<string, number[]> */ },
});
// 卸载：off()
```
`WsEnvelope<T>`、`FishStatePayload`、`ArenaEventsPayload`、`JobProgressPayload`、`BrainActivationPayload`、`WsHandlers`。`connectWs()` 是底层原语（一般不用）。**禁**：面板自己 `new WebSocket`。

## 7. `src/store/ui.ts` — 全局低频状态

`useUiStore` 状态：`running`、`sessionId`、`selectedFishId`、`resetNonce`、`stats: ArenaStats | null`、`activeView: ViewId`；动作：`setRunning/toggleRunning`、`setSessionId`、`setSelectedFish`、`setStats`、`setActiveView`、`bumpReset`。`ViewId = "evolution" | "experiment" | "playback"`。
**禁**：把 20Hz 数据放 store（README 防坑 3）。

## 8. npm 脚本与强制

| 脚本 | 作用 |
|---|---|
| `npm run lint:design` | 扫 `src/**` 违规样式 + **校验 index.css 与 tokens.ts 一致**（失败即非零退出） |
| `npm run gen:design` | 从 `tokens.ts` 重写 `index.css` token 块 |
| `npm run build` / `npm run lint` | 类型/构建、eslint |

**违规触发**：字面 `#hex` / `rgb(` / `hsl(`、`{gray,slate,…}-数字`、`rounded*`、`shadow*`、`blur*`、`gradient`、`transition-colors`。豁免：`design/palette.ts`、`design/tokens.ts`、`index.css`。

## 9. 扩展点（新增东西时改哪里）

| 要加 | 改哪 |
|---|---|
| 颜色 / 主题 token | `design/palette.ts` 或 `design/tokens.ts` → `npm run gen:design` |
| 几何常量 / 比例 | `design/geometry.ts` |
| 字体 | `design/typography.ts` |
| 后端端点 / 类型 | `api/types.ts` + `api/arena.ts`（新资源可另开 `api/<x>.ts`，但类型仍归 `types.ts`） |
| 推送信道 | `api/ws.ts`（加 `type` → payload 接口 → `subscribe` 分支） |
| 视图 | `store/ui.ts` 的 `ViewId` + `App.tsx` 渲染 + `ViewTabs` 文案 |
| 新面板 | `src/panels/<Name>Panel.tsx`，套 `Panel` 外壳，只引用通用层 |

**新增文件自查**：① 有无颜色/几何字面量？② 是否 import 了通用层而非自己造？③ `npm run lint:design && npm run lint && npm run build` 是否全绿？
